## Rule

`deps` runs `npm ci --omit=dev --omit=optional --ignore-scripts` from the lockfile with `--cache` set to a directory that the same `RUN` removes. `runtime` has no `RUN` that invokes `npm` and copies into `/app` only `dist/` (from `build`), `node_modules/` (from `deps`), `package.json`, `package-lock.json`, `LICENSE`, `NOTICE` and `README.md`. The runtime image contains no `/app/src`, `/app/tests`, `/app/scripts`, `/app/.git`, `/app/secrets`, `/app/.env*`, no `node_modules/typescript` or `node_modules/vitest`, no `node_modules/@napi-rs` directory and no `*.node` file under `/app/node_modules`. In the runtime image, `node --input-type=module -e "await import('/app/dist/extraction-pdf.js')"` exits 0.

**v2 (F-034 v2, #4, pending acceptance; v1 stays the accepted rule until then)** — v1 holds, except that `runtime` also copies `LICENSES/Apache-2.0.txt` into `/app/LICENSES/`: the files it copies into `/app` are `dist/` (from `build`), `node_modules/` (from `deps`), `package.json`, `package-lock.json`, `LICENSE`, `NOTICE`, `README.md` and `LICENSES/Apache-2.0.txt`.

## Rationale

A small, reproducible runtime without dev tooling, sources or native optional binaries; the build output is valid for both architectures. Source: [F-013 v1](../features/F-013-http-image.md). v2: the character tables of F-034 derive from PDF.js, licensed under Apache-2.0, and its §4(a) requires a copy of the licence with every redistribution, so the npm package and the runtime image ship `LICENSES/Apache-2.0.txt` ([F-034 v2](../features/F-034-pdf-extraction-profile.md)).
