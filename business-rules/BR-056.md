# BR-056 — Fail-closed bounded evidence

## Rule

Missing, failed, contradictory, cyclic, incomplete or over-budget received-share evidence denies without protected dispatch, with the same generic public refusal as the configured-tree route.

The detailed frozen evidence, capability, cache and effect contracts in
[F-004 v1](../features/F-004-received-share-policy.md) are normative.

## Rationale

Incomplete or contradictory proofs cannot confer authority.

## Examples

These are synthetic injected examples, not provider observations.

- **Given** received evidence that remains pending, **When** checking a shared read, **Then** no completion or protected execution occurs.
- **Given** received evidence that throws a raw object or has an untrusted accessor, **When** checking a shared read/discovery, **Then** ACCESS_DENIED is returned without leaking raw evidence or invoking the accessor.

Each example maps to the named parameter row/group below, in the same order.
