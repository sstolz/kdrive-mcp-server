# BR-004 — Distribution and provenance boundary

## Rule

distribute original-code MIT license, README, NOTICE and built bin.
NOTICE records upstream repository, pinned revision, actual MIT declarations and
absence of copied source. A positive package allowlist excludes private files,
source, tests and reports. Ignore `.env`, `.env.*` except `.env.example`, private
key suffixes, `secrets/`, dependencies, outputs and archives. The environment
example contains empty name/value placeholders only; read/generate no secrets.

## Rationale

avoid private material distribution and invented upstream provenance.
