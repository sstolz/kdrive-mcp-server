## Rule

GET on the PRM URL returns 200 `application/json` with members exactly `resource` (`P`, which BR-152 also makes the audience that F-010 BR-128 and the verifier compare), `authorization_servers` (`[P]`) and `bearer_methods_supported` (`["header"]`).

## Rationale

MCP clients discover the authorization server through the protected-resource metadata (RFC 9728). Source: [F-012 v1](../features/F-012-authenticated-http.md), AC-04.

## Examples

- **Given** public URL `https://mcp.test/mcp`
  **When** GET `/.well-known/oauth-protected-resource/mcp`
  **Then** 200 with `resource` and the only authorization server both `https://mcp.test/mcp`.
