# BR-001 — Diagnostic ESM executable

## Rule

`kdrive-mcp-server` is ESM for Node `>=26.13.0 <27`, builds
`dist/cli.js` and exposes that bin name. Exactly `--version` prints the package
version and exits 0; exactly `--help` prints diagnostic usage and exits 0.
Every other invocation prints `Server runtime is not implemented yet.` to stderr
and exits 1. These paths make no requests, read no deployment configuration and
start no server.

## Rationale

provide honest executable package diagnostics before product runtime.

Historical examples only. This rule is superseded by [BR-016](BR-016.md); these scenarios make no current-behavior or new execution claim.
