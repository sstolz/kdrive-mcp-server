# BR-271 — One request per attempt on the kind's route

## Rule

Each registered mutator sends exactly one request per attempt, on the route of the F-017 Route table for its kind, with the operation's IDs, and no other request (no read-back); the `restore` request has no body and no `destination_directory_id`.

## Rationale

The decision covers exactly one write; a read-back would change the F-016 classification (D-17-10). Source: [F-017 v1](../features/F-017-controlled-tree-mutations.md).

## Examples

- **Given** a permitted move of 20 into 30 on drive 101
  **When** the tool is called
  **Then** exactly one `POST /3/drive/101/files/20/move/30` is sent
- **Given** a lost response to a restore
  **When** the run ends
  **Then** no request of any kind follows the restore request
