# BR-432 — Deprecated stable default recovery

## Rule

A deprecated stable npm latest is an admissible default for a stable candidate and is refused for a beta candidate.

The exhaustive predicates and diagnostics are in
[F-024 v4](../features/F-024-gated-publication.md), ticket #91.

## Rationale

Permit a forward stable fix while keeping the vulnerable version deprecated, including when no healthy earlier stable exists; owner decision 2026-11-17, #91. All other gates remain mandatory.

## Examples

- **Given** deprecated stable latest 1.0.0 and matching GHCR defaults
  **When** preflight checks candidate 1.0.1
  **Then** passes the default predicate without removing deprecation.
- **Given** deprecated stable latest 1.0.0 and matching GHCR defaults
  **When** preflight checks candidate 1.1.0-beta.1
  **Then** fails the default predicate.
