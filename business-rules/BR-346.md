# BR-346 — Privacy scan of the commit range

## Rule

The range is `<base>..<head>` from `PRIVACY_RANGE_BASE` and `PRIVACY_RANGE_HEAD`: on `pull_request` the PR base and head, on `push` `before..after`. The full history of the head is scanned instead when `PRIVACY_EVENT` is `workflow_dispatch`, or the base is empty, forty zeros (new branch) or not a commit in the clone. A base that is not an ancestor of the head keeps the range scan. For each commit of `git rev-list <range>`: its full message (`git log -1 --format=%B`) is scanned by the BR-345 views; its author and committer name and e-mail (`%an`, `%ae`, `%cn`, `%ce`) are scanned by the same views and reported as `commit <40-hex sha> identity`; and its changed blobs are scanned: `git diff-tree -r --no-renames --no-commit-id --root -z <commit>` (merge commits list no blobs) gives every path and its new blob id; each new blob that is neither all-zero (deleted entry) nor a gitlink is read through `git cat-file --batch` and scanned whole with the BR-345 decoders (a cache private to the commit scan reads each blob id once; these blobs do not count toward `<f>`); each path of the entry (including deleted paths) is scanned as text. Hits in a commit's blobs or paths are reported as `commit <sha> added`; binary blobs add to `<b>` once per blob of the commit scan. An empty head, or a head that is not a commit in the clone, prints only `privacy-scan: head is not a commit` and exits 2.

## Rationale

Commit messages, identities and intermediate blobs become public with the history, not only the final tree; the squash message comes from the PR (D-6). Source: [F-023 v1](../features/F-023-hosted-ci-privacy-scan.md).

## Examples

- **Given** commits A–C with the token only in B's message and in a blob that C adds
  **When** the scan runs with base A and head C
  **Then** `commit <B> line 3` and `commit <C> added` are reported
- **Given** the same commits
  **When** the scan runs with base C
  **Then** no commit hit is reported
- **Given** an empty head
  **When** the scan runs
  **Then** it prints only `privacy-scan: head is not a commit` and exits 2
