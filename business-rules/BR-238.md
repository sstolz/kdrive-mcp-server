## Rule

With `auditLog` equal to `stderr`, records are written only to file descriptor 2 and never to stdout; otherwise to the configured absolute file path; the sink is opened at startup only when the configured mode is `write` or `share`, and never in mode `read`.

## Rationale

Read mode has nothing to audit; stdout carries MCP frames only (D-16-12, BR-069 v2). Source: [F-016 v1](../features/F-016-mutation-audit-gate.md).

## Examples

- **Given** mode `write` with `auditLog=stderr`
  **When** a run completes
  **Then** stderr holds the intent and outcome records and stdout only MCP frames
- **Given** mode `read` with a file path
  **When** the server starts
  **Then** the file is not created
