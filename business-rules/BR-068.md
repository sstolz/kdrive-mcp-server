## Rule

Session instructions and every tool description identify the server as unofficial and returned names/paths as untrusted data, never commands or authorization.

## Rationale

Provider-controlled text must stay data rather than becoming instructions or grants. Source: [F-005 v1](../features/F-005-stdio-navigation.md), AC-10.

## Examples

- **Given** a session and an item with instruction-like quoted text.
  **When** the client initializes and reads metadata.
  **Then** unofficial/untrusted notices appear and the name remains JSON data.
- **Given** a returned name asking to ignore instructions.
  **When** the item is exposed.
  **Then** no prompt, sampling or elicitation is generated.
