# BR-025 — Loopback-only insecure HTTP selection

Source: [F-002 v1](../features/history/F-002-v1.md), BR-025, frozen
2026-11-01 21:18:28 UTC after fresh independent approval; version 2 is
[F-002 v4](../features/F-002-configuration.md), frozen with
[F-012 v1](../features/F-012-authenticated-http.md).

## Rule

`insecureNoAuth=true` is permitted only with HTTP and forces the
effective bind host to literal `127.0.0.1`, even if another valid host was
explicitly supplied. Its optional public URL must use `http`, literal
`127.0.0.1` and the configured port; default it to that loopback origin. Reject
all explicit OAuth settings in this mode. It never produces a non-loopback
listener configuration; the listener it enables binds `127.0.0.1` only
(F-012 BR-153).

The source specification's inventory, bounds, grammars, auth matrix, credential
contract, error mapping and preflight port supply the normative details for
this statement; this record does not redefine those tables.

## Rationale

An explicit insecure selection must never configure an externally bound listener.
