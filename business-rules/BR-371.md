# BR-371 — npm publishes only after the image push

## Rule

`publish-npm` `needs` `publish-image`, so `make release-npm` runs only after `make release-image` succeeded and a failed image push publishes nothing to npm.

## Rationale

The image is the harder publication to retract; npm follows only once it exists. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** the real `release.yml`
  **When** the validator runs
  **Then** `publish-npm` needs `verify` and `publish-image`
- **Given** `publish-npm` without `publish-image` in `needs`
  **When** the validator runs
  **Then** it throws
