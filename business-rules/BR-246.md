## Rule

Every admitted run is decided by the guarded facade `dispatch` of the same policy instance that serves tools and resources; a denial returns `denied` with code `ACCESS_DENIED`, makes zero intent records and zero upstream attempts, and attempts one `denied` record whose failure leaves the result unchanged.

## Rationale

Every mutation goes through the one shared fail-closed policy facade (BR-043). Source: [F-016 v1](../features/F-016-mutation-audit-gate.md).

## Examples

- **Given** a policy denial
  **When** a run starts
  **Then** the result is `denied`/`ACCESS_DENIED` with one `denied` record and no intent
- **Given** a denial with a failing sink
  **When** a run starts
  **Then** the result is unchanged
