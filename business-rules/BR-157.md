## Rule

On the MCP endpoint, a request carrying `Origin` is refused with HTTP-layer error 403 `invalid_origin` unless the value equals the origin of `P` exactly (insecure mode: or that origin with hostname `localhost`). On `/oauth/consent` the same rule applies, except that the value `null` also passes (D-15). A request without `Origin` passes. The check runs after routing and before authentication. Other routes ignore `Origin`.

## Rationale

Origin validation on the MCP endpoint and the consent form blocks cross-origin browser requests. Source: [F-012 v1](../features/F-012-authenticated-http.md), AC-05.

## Examples

- **Given** the MCP endpoint
  **When** a request carries `Origin: https://evil.test`
  **Then** 403 `invalid_origin`.
- **Given** `/oauth/consent`
  **When** a request carries `Origin: null`
  **Then** it reaches the consent handler.
