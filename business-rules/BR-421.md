# BR-421 — Trusted reverse proxies setting

## Rule

The F-002 setting `httpTrustedProxies` (environment `MCP_HTTP_TRUSTED_PROXIES`, comma-separated like the other list settings; option `--http-trusted-proxies`; YAML `httpTrustedProxies`) is an optional list, default empty, of at most 64 entries; an empty value (`MCP_HTTP_TRUSTED_PROXIES=`, YAML `[]`) is the empty list, as for BR-291. Each entry is an IPv4 address in dotted-decimal form without leading zeros, or an IPv6 address byte-identical to the WHATWG URL serialisation of itself (lowercase, compressed, no zone, no brackets, no dotted IPv4 part) and not inside `::ffff:0:0/96` (IPv4-mapped); either may be followed by `/` and a prefix length without a leading zero, 8–32 for IPv4 and 8–128 for IPv6, with no address bit set after the prefix. An entry without a prefix stands for `/32` (IPv4) or `/128` (IPv6). Any other entry is refused with `INVALID_VALUE`, and so is a list of more than 64 entries or with two entries naming the same prefix (for example `192.0.2.1` and `192.0.2.1/32`); overlapping prefixes of different lengths are accepted. The setting is accepted only with transport `http`, authentication on and OAuth mode `proxy` (the BR-290 restriction); set explicitly in any other configuration, the empty list included, it is refused with `CONFLICTING_SETTINGS`, as BR-291 is. It is read at startup only.

## Rationale

Behind a reverse proxy every socket peer is the proxy, so per-client admission (BR-162 v3) needs the client address the proxy forwards; trusting that header from anyone would let a client choose its own peer, so only listed proxies are trusted and the default trusts none (F-035 D-4). Source: [F-035 v1](../features/F-035-oauth-proxy-hardening.md).

## Examples

- **Given** `MCP_HTTP_TRUSTED_PROXIES=127.0.0.1,192.0.2.0/24,2001:db8::/32` in `proxy` mode
  **When** the configuration loads
  **Then** it is accepted with three entries
- **Given** an entry `10.0.0.0/8`, then `10.0.0.0/7`
  **When** the configuration loads
  **Then** accepted, then `INVALID_VALUE`
- **Given** an entry `2001:db8::/128`, then `2001:db8::/129`
  **When** the configuration loads
  **Then** accepted, then `INVALID_VALUE`
- **Given** 64 entries, then 65
  **When** the configuration loads
  **Then** accepted, then `INVALID_VALUE`
- **Given** `MCP_HTTP_TRUSTED_PROXIES=` (empty) in `proxy` mode
  **When** the configuration loads
  **Then** it is accepted as the empty list
- **Given** `fc00::/7`
  **When** the configuration loads
  **Then** `INVALID_VALUE`
- **Given** `192.0.2.1` and `192.0.2.1/32` in one list
  **When** the configuration loads
  **Then** `INVALID_VALUE`
- **Given** a valid entry, then the empty value, with transport `stdio`
  **When** the configuration loads
  **Then** `CONFLICTING_SETTINGS` both times
