# BR-368 — Beta dist-tag and one version image tag

## Rule

For a version `<x.y.z>-beta.<n>`, the npm dist-tag is exactly `beta` and the only image reference pushed is exactly `ghcr.io/sstolz/kdrive-mcp-server:<version>`. No mode passes `--tag latest` to npm, runs `npm dist-tag` or pushes an image tag `latest`.

## Rationale

A pre-release never becomes the default install; npm `latest` stays on the P-0 placeholder. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** dry run `true`
  **When** `release-npm` runs
  **Then** the publish argv has `--tag beta` and no `latest`
- **Given** a real image run
  **When** `release-image` runs
  **Then** the build has exactly one `--tag ghcr.io/sstolz/kdrive-mcp-server:0.6.0-beta.1` and no `latest`
