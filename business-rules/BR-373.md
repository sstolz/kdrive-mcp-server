# BR-373 — Image read-back

## Rule

### v2 — accepted (active)

Accepted on main `6a508ab` (#89 comments `89-acceptance-1-claude` and `89-acceptance-2-owner`).

Image read-back keeps the v1 OCI index or Docker manifest
list check for `<version>` with exactly `linux/amd64` and `linux/arm64`
among non-attestation entries. For beta, `latest` remains absent or has
another digest, as in v1. For stable, `<version>` and `latest` both return
200 and resolve to exactly `RELEASE_IMAGE_DIGEST` from this run.
Beta read-back stays unchanged from v2 and requires no run digest. An anonymous token request
and anonymous manifest HEAD must succeed for both stable references.
Digest comparisons use GET and the BR-363 v2 Accept list. HEAD is only
an anonymous access check. Both stable tags must serve the checked index.
Binding both tags to this run is mandatory, not a residual risk.
The printed line remains `release-verify: image digest sha256:<hex>`.
Fixed per-condition output and success only when every condition holds
remain unchanged.

### v1 — accepted (superseded by v2)

`release-verify` reads the GHCR manifest of tag `<version>` with a pull token: it is an OCI image index or Docker manifest list whose non-attestation entries have exactly the platforms `linux/amd64` and `linux/arm64`, and tag `latest` returns 404 or another digest. It prints `release-verify: image digest sha256:<hex>`. The check `image is public (P-3)` requests an anonymous pull token and then `HEAD` the manifest with it, passing only when both return 200. It prints one line per condition like BR-365 and exits 0 only when all hold.

## Rationale

The pushed image must serve both platforms publicly, must not be `latest`, and its digest must be printed so users can pin it. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** an index with `linux/amd64` and `linux/arm64` and a public package
  **When** `release-verify` runs
  **Then** it passes and prints the index digest
- **Given** an index lacking `linux/arm64`
  **When** `release-verify` runs
  **Then** it fails
