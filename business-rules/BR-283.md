# BR-283 — `kdrive_upload` description sentences

## Rule

The `kdrive_upload` description contains the fixed sentences of the F-018 Tool text and the BR-263 sentence, and the input schema description of `overwrite` contains the F-018 Overwrite sentence.

Since v2: the `kdrive_upload` description also contains the sentence `name must be in Unicode NFC (composed form); other forms are refused.`

## Rationale

Clients must be told that `overwrite:false` is observed kDrive behaviour, not a guarantee (D-18-1). Source: [F-018 v1](../features/F-018-upload.md).

## Examples

- **Given** mode `write`
  **When** tools are listed
  **Then** the description contains "this refusal is observed kDrive behaviour, not a guarantee of this server."
- **Given** mode `write`
  **When** the `overwrite` schema is read
  **Then** its description begins "false (default): kDrive is asked to refuse"
