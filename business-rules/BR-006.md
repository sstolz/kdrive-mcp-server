# BR-006 — Mandatory npm CI policy (historical)

## Rule

```text
Every PR against `main` and every push to `main` runs workflow
  `CI`, without path filters, with stable jobs `lint`, `format`, `typecheck`,
  `test` and `build`. Each installs using `npm ci` and runs its corresponding
  command; `build` also checks the packed artifact/executable. Failed steps fail
  the job. Permissions are `contents: read`; there are no publish/release/tag
  steps, write permissions, deployment secrets or tag-triggered release paths.
```

## Rationale

Historical preservation only: retain the allocated definition and its successor chain without implying implementation or acceptance. This editorial rationale does not amend the frozen rule.
