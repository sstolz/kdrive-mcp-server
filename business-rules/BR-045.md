# BR-045 — Independent all-target batches

## Rule

A multi-target protected operation dispatches nothing unless its effects are independent under the batch contract below and every target and derived effect passes one shared authorization invocation.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Do not compose effects that can change the meaning of a separately checked target.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** independent files 13 and 14 under the same unchanged parent, **When** replacing both in one batch, **Then** one protected batch dispatch occurs.
- **Given** the same batch with missing file 99 as second target, **When** dispatching it, **Then** zero protected calls occur.

Both examples map to the test or parameter rows named below.
