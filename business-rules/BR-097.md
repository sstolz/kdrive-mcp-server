## Rule

A pasted redirect URL is accepted only when its origin and path equal the redirect URI and its `state` equals the issued state; an `error` or a missing code ends the run with the error code only. The token exchange sends `grant_type=authorization_code`, the code, the redirect URI, the PKCE verifier and `resource`; with a secret it uses `client_secret_basic` (credentials form-urlencoded before Base64) when that method is `yes` or `unknown`, else `client_secret_post` when `yes`, else stops; without a secret it sends `client_id`. The secret is read only from a no-echo prompt, and any environment variable whose name contains `CLIENT_SECRET` makes the command exit nonzero before any request.

## Rationale

A forged or mismatched redirect must never be exchanged, and the client secret must never reach arguments, the environment, files or the repository. Source: [F-008 v1](../features/F-008-oidc-qualification.md), AC-06, AC-07.

## Examples

- **Given** a secret `a:b+c%` and token auth methods absent.
  **When** the code is exchanged.
  **Then** the request carries `Authorization: Basic` of `synthetic-client:a%3Ab%2Bc%25`.
- **Given** token auth methods `["private_key_jwt"]` and a secret.
  **When** the exchange would start.
  **Then** no token request is sent.
- **Given** `OIDC_CLIENT_SECRET` set.
  **When** the command starts.
  **Then** it exits nonzero before any request.
