## Rule

Audit records, gate errors and every gate-authored result member never contain item names, paths, search queries, e-mail domains, file content, tokens, credentials, HTTP headers, URLs, provider response bodies or exception text. The mutator's validated `value` (BR-255) passes through to the caller unchanged and is never recorded.

## Rationale

Names, paths, tokens and provider text are sensitive or untrusted; IDs are enough to correlate with kDrive history (D-16-3). Source: [F-016 v1](../features/F-016-mutation-audit-gate.md).

## Examples

- **Given** a rename named `SECRETMARK` and a mutator throwing `SECRETMARK`
  **When** the run ends `uncertain`
  **Then** no record, result member or diagnostic contains `SECRETMARK`
- **Given** a mutator value `{name:"SECRETMARK"}` on a 200
  **When** the run succeeds
  **Then** the result `value` carries it and no record does
