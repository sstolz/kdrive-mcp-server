# BR-353 — Scoped lockfile and tarball name

## Rule

`package-lock.json` has top-level `name` and `packages[""].name` both exactly `@sstolz/kdrive-mcp-server`, and `make pack` writes exactly one tarball, `artifacts/sstolz-kdrive-mcp-server-<package.json version>.tgz`.

## Rationale

The lockfile and the packed artifact must carry the scoped npm name the owner chose on 2026-11-12, so that the tarball the release publishes is the one `make pack` built. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** the lockfile of this repository
  **When** its names are read
  **Then** both `name` and `packages[""].name` are `@sstolz/kdrive-mcp-server`
- **Given** package version `0.1.0`
  **When** `make pack` runs
  **Then** the only tarball is `artifacts/sstolz-kdrive-mcp-server-0.1.0.tgz`
