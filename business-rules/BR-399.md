# BR-399 — Proxy page shell

## Rule

Every HTML page of the proxy (consent page and every error page) is one document of this shape, in this order: `<!doctype html>`; `<html lang="en">`; in `<head>`, `<meta charset="utf-8">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`, `<meta name="color-scheme" content="light dark">`, `<title><page title> · kdrive-mcp-server</title>` and exactly one `<style>` element whose content is the fixed stylesheet of BR-400; in `<body>`, exactly one `<header>`, one `<main>` and one `<footer>`. The header holds one inline `<svg>` mark with `aria-hidden="true"` and `focusable="false"` and no `href`/`xlink:href`, the product name `kdrive-mcp-server` and the line `Unofficial MCP server for kDrive, not affiliated with Infomaniak.` The main holds exactly one `<h1>` (the page title). The footer holds exactly one link, `<a href="https://github.com/sstolz/kdrive-mcp-server" target="_blank" rel="noopener noreferrer">Source code on GitHub</a>`; it is the only `<a>` of the document, is outside `<main>` and `<form>`, and has no button class. The document contains no `<script>`, `<link>`, `<img>`, `<iframe>`, `<object>`, `<embed>`, `<base>`, `<meta http-equiv>`, `on*` attribute and `style` attribute, and no absolute URL other than the GitHub link and the HTML-escaped `ConsentView` values of BR-402 (`clientId`, `clientName`, `cimd.host`, `redirectUri`, `resource`, `action`, which come from the request, the client's registration or document, or the configuration). The `<svg>` carries no `xmlns` attribute (not needed in HTML).

**v2 (F-031 v1, #31; accepted on main `901f7af`)** — v1 holds, except: `<html lang="xx">` carries the page language; the `<title>` page title, the header line and the GitHub link text are the page language's catalogue texts (`productTagline`, `sourceLink`; English unchanged); the header ends with the BR-408 `<nav>` on the consent page; the document's `<a>` elements are the GitHub link and, on the consent page when BR-408 offers it, the one switcher link (outside `<main>` and `<form>`, no button class); the switcher `href` is a relative reference starting with `?` and is not an absolute URL.

## Rationale

Before F-030 the pages were unstyled and did not say which product the user was in nor that it is unofficial; one shell keeps every page identical in structure and free of active or external content. Source: [F-030 v1](../features/F-030-oauth-proxy-page-design.md).

## Examples

- **Given** the consent page of a registered client
  **When** it is rendered
  **Then** it has the BR-399 head, one style, the header with the mark, `kdrive-mcp-server` and the unofficial line, one `<main>` with one `<h1>`, and the GitHub link as the only `<a>`, in the footer
- **Given** a consent view whose values contain `<script>`, `" onload="`, `style=`, `http://evil.example` and `javascript:`
  **When** the page is rendered and the escaped values are removed
  **Then** no forbidden element or attribute and no URL other than the GitHub link remains
- **Given** a French consent page with the switcher (v2)
  **When** it is rendered
  **Then** it has `<html lang="fr">`, the French title, header line and GitHub link text, the `<nav>` as the header's last child, and exactly two `<a>` elements
