## Rule

Unsupported binary and unsupported containers return declared fixed results and never fall back to lossy text or a different representation.

## Rationale

Unsupported binary or container features need explicit refusals rather than misleading text. Source: [F-009 v1](../features/F-009-bounded-content-reading.md).

## Examples

- **Given** GIF89a requested as an image.
  **When** read runs.
  **Then** UNSUPPORTED_FORMAT is returned.
- **Given** image arguments containing offset0.
  **When** validation runs.
  **Then** INVALID_ARGUMENTS occurs before protected calls.
