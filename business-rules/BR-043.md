# BR-043 — Immediate guarded dispatch

## Rule

Tools and resources dispatch protected work only through the same guarded facade, which checks the exact immutable operation and immediately consumes its single-use authorization within that invocation.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Bind execution to the exact immutable operation and current invocation.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** a read of file 13 whose caller object is changed to 999 during inspection, **When** dispatching the original read, **Then** execution receives immutable target 13.
- **Given** the caller subsequently dispatches target 999, **When** checking it afresh, **Then** it is denied with no reused grant.

Both examples map to the test or parameter rows named below.
