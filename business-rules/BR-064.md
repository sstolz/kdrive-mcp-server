## Rule

Listing returns only authorized direct children of the exact authorized directory scope, optionally filtered by file/directory type.

## Rationale

Listing scope is narrower than all items allowed somewhere in the same drive. Source: [F-005 v1](../features/F-005-stdio-navigation.md), AC-06.

## Examples

- **Given** directory /docs with permitted child a.
  **When** list requests /docs.
  **Then** the child appears once.
- **Given** a sibling /b or contradictory duplicate identity.
  **When** list requests /docs.
  **Then** the sibling is omitted and conflicting evidence refuses.
