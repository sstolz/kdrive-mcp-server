## Rule

When an upstream response has status 401 or 403, the adapter reports it to the composition, which emits at most one operator event per 60,000 ms of monotonic time: in stdio mode the stderr line exactly `kDrive upstream refused a request (<status>).`, in HTTP mode the stderr JSON line exactly `{"event":"kdrive_upstream_refused","status":<status>}`. The event carries no other field; the client-visible result is unchanged (Error-mapping table). Likewise, when a request fails unbranded for a timeout, DNS/address, TLS, socket or queue-full cause, the composition emits at most one such event per 60,000 ms, in a rate window separate from the refused-event window (timeout → `timeout`; DNS failure, address refusal or socket error → `network`; TLS → `tls`; queue full → `queue`; abort, size and encoding failures emit nothing): in stdio mode the stderr line exactly `kDrive upstream unavailable (<class>).`, in HTTP mode exactly `{"event":"kdrive_upstream_unavailable","class":"<class>"}`, where `<class>` is one of `timeout`, `network`, `tls`, `queue`; no other field. Both event kinds are emitted only once preflight has succeeded: a refusal or an unavailable cause during preflight emits no event, and the single BR-016 v2 configuration-error line remains the only stderr output of a failed preflight (BR-175 v2). Verified by: AC-28.

## Rationale

An expired token or an outage must be distinguishable from a policy denial for the operator, without flooding logs or leaking data. Source: [F-014 v2](../features/F-014-production-kdrive-adapter.md).

## Examples

- **Given** 401 answers at 0, 10,000 and 59,999 ms then 403 at 60,000 ms in stdio mode
  **When** each `kdrive_info` call runs
  **Then** stderr holds `kDrive upstream refused a request (401).` then `... (403).`.
- **Given** two timeouts then a TLS failure within 60,000 ms in HTTP mode
  **When** each call runs
  **Then** stderr holds one `{"event":"kdrive_upstream_unavailable","class":"timeout"}` line.
- **Given** an init 401 during preflight
  **When** `main` runs
  **Then** stderr holds only `Configuration error [PREFLIGHT_FAILED] (preflight).`.
