# BR-318 — skipLibCheck with a locally typed resize call

## Rule

`tsconfig.json` `compilerOptions` deep-equals its value on the base plus `skipLibCheck: true`; `tsconfig.build.json` sets no `skipLibCheck` of its own. Project sources and tests stay fully type-checked (BR-010 unchanged). Because `ResizeOptions` of `@jimp/plugin-resize` resolves to `any` under this setting, `src/extraction-image.ts` declares a local type for the resize options (`{ w: number; h: number; mode: ResizeStrategy }`, exported for the test), builds the options as a value of that type, and passes that value to `image.resize`; it passes no inline object literal.

## Rationale

Jimp's declarations name Zod 3 types that Zod 4 lacks, so `tsc` fails on them without `skipLibCheck`; the local type restores a check at the one call whose library type became `any` (D-5, ADR-009). Source: [F-020 v1](../features/F-020-dependency-audit.md).

## Examples

- **Given** `tsconfig.json` and `tsconfig.build.json`
  **When** the test parses them
  **Then** `compilerOptions` equals the base plus `skipLibCheck: true`, and the build config has no `skipLibCheck`
- **Given** an `ImageResizeOptions` value with `mode: "nearest"`
  **When** `tsc` runs
  **Then** it is a type error (`@ts-expect-error` used)
- **Given** an `ImageResizeOptions` value without `h`
  **When** `tsc` runs
  **Then** it is a type error (`@ts-expect-error` used)
- **Given** `ResizeOptions` of `@jimp/plugin-resize`
  **When** `tsc` runs
  **Then** it is `any`; the assertion fails once a Jimp release fixes the type
