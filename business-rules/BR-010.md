# BR-010 — Separate reproducible local quality checks

## Rule

v2 (F-011, accepted on main `bc09d56`; v1 below is kept for history):

Make delegates install, lint, format, typecheck, test, build and pack to the
specified non-watch npm commands in the Compose dev service using the lockfile.
Typed ESLint applies the typescript-eslint `strictTypeChecked` configuration,
`@typescript-eslint/no-floating-promises` and the `eslint-plugin-sonarjs` 4.2.2
`recommended` configuration to `src/**/*.ts`, `tests/**/*.ts`,
`scripts/**/*.ts` and `vitest.config.ts`, and rejects warnings. Prettier checks
without writing; TypeScript checks source and tests; empty test discovery and
build type errors fail. (v1: `recommendedTypeChecked` without SonarJS.)

v1 (accepted):

Make delegates install/lint/format/typecheck/test/build/pack to the
specified non-watch npm commands in Compose dev using the lockfile. Typed
ESLint/typescript-eslint recommended rules include no-floating-promises and reject
warnings. Prettier checks without writing; TypeScript checks source/tests; empty
test discovery and build type errors fail.

## Rationale

distinguish quality concerns and preserve reliable nonzero failures.
