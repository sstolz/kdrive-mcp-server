## Rule

v2 (F-020 v1, #104; accepted on main `b6acf86`, 2026-11-11): v1 holds (pure-JS extraction, no external request, no native/WASM codec, no eval, scalar-only Jimp schema surface with no `z.array|record|map|set`), and the Jimp schemas run on the single root `zod` of BR-316 instead of a nested Zod 3.

Extraction/image dependencies execute without external requests, optional native/WASM codecs, eval or document-supplied JavaScript.

## Rationale

Exact pinned JavaScript execution and closed loader paths keep runtime requirements reproducible. Source: [F-009 v1](../features/F-009-bounded-content-reading.md).

## Examples

- **Given** locked runtime installed with dev/optional dependencies omitted.
  **When** compiled PDF and PNG workers run.
  **Then** both succeed without native canvas.
- **Given** untrusted image collections in unknown arguments.
  **When** tool validation runs.
  **Then** they never reach Jimp scalar resize schemas.
