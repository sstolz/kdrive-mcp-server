## Rule

An `uncertain` classification ends the run without any further upstream attempt, and its result carries code `UPSTREAM_UNCERTAIN` and the fixed message `The upstream result is unknown; verify the item's state before any new attempt.`

## Rationale

An unknown result must not be replayed and the client must verify state first (SPEC §6). Source: [F-016 v1](../features/F-016-mutation-audit-gate.md).

## Examples

- **Given** an attempt answering 503
  **When** the run ends
  **Then** the mutator was called once and the result is `uncertain` with the fixed message
- **Given** a connection loss
  **When** the run ends
  **Then** the result is the same
