# BR-333 — Degraded issues line on 401 or 403

## Rule

When the issues request answers 401 or 403, the summary prints exactly `Quality Gate issues unavailable (HTTP <status>): the token may lack Browse permission on the project.` after the conditions already printed; this line replaces the BR-332 issues stage line, so exactly one line is printed for that stage. Any other non-2xx status on issues, including HTTP 400 (for example a server rejecting `s=SEVERITY`), prints the BR-332 issues stage line.

## Rationale

The existing analysis tokens may lack Browse permission (D-1). Source: [F-022 v1](../features/F-022-sonar-gate-summary.md).

## Examples

- **Given** conditions printed and the issues request answering HTTP 403
  **When** the summary runs
  **Then** it prints `Quality Gate issues unavailable (HTTP 403): the token may lack Browse permission on the project.` and no issues stage line
- **Given** the issues request answering HTTP 400
  **When** the summary runs
  **Then** it prints `Quality Gate summary unavailable: issues stage failed (HTTP 400).` and no Browse line

## Verification

tests/sonar-summary.test.ts: `BR-333 degraded issues`, `BR-333 issues HTTP 400`. Run with Docker/Make `make check`; no Sonar server, network or secret is used.
