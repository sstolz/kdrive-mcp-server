## Rule

Configured collection scopes execute in configuration order and preserve upstream page order without global sorting.

## Rationale

Root-local provider order must survive bounded multi-root traversal. Source: [F-006 v1](../features/F-006-filtered-pagination.md).

## Examples

- **Given** roots A then B with overlapping entries.
  **When** search follows consecutive cursors.
  **Then** A pages precede B and first occurrences keep provider order.
- **Given** an explicit folder.
  **When** recents runs.
  **Then** only that scope is requested.
