# BR-034 — Exact deny matching

## Rule

An affected current or resulting path matching a configured deny pattern under the matching contract below produces a denial, including under root ID `1`.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Apply the configured grammar to every affected current and resulting path.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** deny /private/** and path /private, **When** checking a read, **Then** the path is denied.
- **Given** deny /private/** and path /private2/a, **When** checking a read, **Then** the pattern does not deny it.
