## Rule

`createHttpHandler`, and therefore `createHttpServer` and `startHttpServer`, raise `HttpStartupError` code `CONFIGURATION_UNSUPPORTED` unless the configuration satisfies `isResolvedConfiguration` (F-002 BR-021) and its `transport` is `http`. With `insecureNoAuth` true, an `upstream` option raises `UPSTREAM_PORT_UNEXPECTED`. With `insecureNoAuth` false, these checks run in order: an `oauthMode` other than `proxy` raises `OAUTH_MODE_UNSUPPORTED`; a public URL whose path is `/` raises `PUBLIC_URL_PATH_REQUIRED` (D-9); an absent `upstream` option raises `UPSTREAM_PORT_REQUIRED`. Otherwise the proxy is built with `createOAuthProxy` (F-010 BR-124 v1) from an `EffectiveProxyConfig` mapped from the configuration only: `publicUrl` and `oauthAudience` are `P`; `oauthIssuer`, `oauthAllowedSubjects`, `oauthAllowedEmails`, `oauthUpstreamClientId`, `oauthUpstreamClientSecret` (resolved by F-002 from the inline value or `oauthUpstreamClientSecretFile`), `oauthSigningKey` (read by F-002 from `oauthSigningKeyFile`) and `oauthAllowedRedirectUris` are the configuration's fields of those names. The proxy receives the `upstream` option, the clock, the random source and the logger (BR-167), and its `verifier` (BR-141 v1) is used. The handler accepts no other source of `P`, the audience, the issuer or the secrets (D-17). An error thrown by proxy construction (for example BR-100 v2's validator refusal) propagates. Each of these happens before any socket is opened, and the `HttpStartupError` messages are fixed strings that echo no configuration value.

Version 2 (F-019 v1, #103; accepted on main `68209fe`, 2026-11-11): with `oauthStateFile` set, the handler opens the store (BR-293–BR-297) before constructing the proxy and before any socket is opened.

## Rationale

A server that starts from a stdio configuration, a delegated mode, an origin-only public URL or without its upstream port would either run unauthenticated or fail after a login; refusing at startup keeps one source for the public URL, audience, issuer and secrets. Source: [F-012 v1](../features/F-012-authenticated-http.md), AC-01, AC-04.

## Examples

- **Given** a stdio configuration
  **When** `createHttpHandler` is called
  **Then** `HttpStartupError` `CONFIGURATION_UNSUPPORTED` is raised and no socket is opened.
- **Given** proxy mode with public URL `https://mcp.test`
  **When** `createHttpHandler` is called
  **Then** `PUBLIC_URL_PATH_REQUIRED` is raised.
- **Given** proxy mode with public URL `https://mcp.test/mcp` and a fake upstream port
  **When** the handler is built
  **Then** `createOAuthProxy` receives `publicUrl` and `oauthAudience` `https://mcp.test/mcp`.
