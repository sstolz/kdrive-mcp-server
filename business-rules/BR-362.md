# BR-362 — Green CI evidence for the release commit

## Rule

The GitHub REST API lists at least one run of workflow `ci.yml` in this repository with `head_sha` equal to `RELEASE_SHA`, `head_branch` `main` and `event` `push` or `workflow_dispatch`, whose job `ci-result` has `conclusion` `success`. A PR run, a failed or skipped `ci-result`, a run on another commit and any non-2xx status fail the check.

## Rationale

Nothing is released from a commit that the full CI gate has not passed on `main`; the check fails closed. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** a successful `push` run on `main` with `ci-result` success
  **When** the CI evidence check runs
  **Then** it passes
- **Given** only a `pull_request` run
  **When** the CI evidence check runs
  **Then** it fails
