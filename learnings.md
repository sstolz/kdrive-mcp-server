- 2026-11-03 — Infomaniak access tokens are opaque (validator 401 `malformed`) while its ID token is usable (archived evidence `runs/11-acceptance-infomaniak-token-1.md`) — Plan Infomaniak behind the P-21 proxy; never weaken the validator to accept it.
- 2026-11-03 — Gitea access JWTs are RS256 with `kid` and `exp` but no `iss`, `aud` or `sub`, and `resource` is not reflected (archived evidence `runs/11-acceptance-gitea-token-1.md`) — Treat Gitea as `proxy-only` too; resource-bound delegation is unavailable.
- 2026-11-03 — A Gitea issuer configured with a trailing slash was refused, because issuer matching is exact and the provider's issuer has none (archived evidence `runs/11-acceptance-gitea-1.md`) — Copy the issuer exactly from the provider's discovery document.
- 2026-11-03 — Concurrent tickets allocated the same F/BR IDs, forcing the F-006→F-008 and BR-072..086→BR-094..108 renumbering of #11 (commit 1362e88) — Re-check the next free F/BR IDs on main just before freeze and again before opening the PR.

- 2026-11-02 — A Node26.13 synthetic stdio child with unread large output stayed alive after stream destruction until its watchdog; dedicated-process termination after owned cleanup passed the same EOF/SIGINT/SIGTERM cases — Own process termination only for the default dedicated stdio composition; embedded callers supply separate owned streams; see the observed failures and correction (archived evidence `runs/8-development-3.md`) and completed gate (archived evidence `runs/8-local-gate-1.md`).

- 2026-11-02 — In this session's Codex collaboration API, `send_message` queues to a completed author while `followup_task` starts its next turn — Use the continuation tool and verify running status before reporting active work; source: the declared tool contracts and #5 orchestrator status observations.

- 2026-11-02 — Two stalled PR #41 review-publication calls did not establish a remote verdict; a PR Conversation comment then published it — Check remote state before retrying a write, separate slow reads from mutations, and use an equivalent channel only where forge enforcement permits; see the head-specific independent verdict (archive PR 41).

- 2026-11-01 — The merged official-scanner wrapper passed actual-main live analysis and built-in Quality Gate waiting on f2d38b32dbbd78059da6754bb11d9b8e561fd645 with the existing Project analysis token (archived evidence `runs/28-acceptance-1.md`); custom Browse-protected probes had blocked that token — Delegate remote validation to the pinned scanner, retain exact-main/fresh-LCOV guards and leave local checks independent of Sonar access; acceptance proves these inputs, not project visibility, future syntax compatibility or enabled CI analysis.
- 2026-11-01 — In the pinned Node 26.13.0 runtime, `/^[A-Za-z]$/iu` matches non-ASCII `ſ` and `K`, while the same class with `u` alone rejects both (archived evidence `runs/31-readiness-1.md`, executed Unicode proof) — Preserve explicit ASCII grammar during refactoring; adding `i` to a Unicode-aware ASCII class can silently widen the accepted configuration language.
- 2026-11-03 — Buffer ASCII decoding clears high bits, and JavaScript numbers erase PDF integer/real lexical distinctions (archived evidence `runs/14-pr48-corrections-2.md`) — Validate framing bytes with exact ASCII ranges and retain numeric token kind until the allowed operand context consumes it.
- 2026-11-03 — Sonar snapshot coverage runs the whole test suite in `artifacts/sonar-input/<run>` without `.git`; a test that calls `git ls-files` passes in `make check` but fails the snapshot (seen in the #50 CI simulation, archived evidence `runs/50-development-1.md`) — Tests read files from the tree, never from Git.
- 2026-11-03 — `docker compose run` of a service with a named volume under a bind mount leaves an empty root-owned mount-point directory (`node_modules/`) in the host checkout; `make setup` creates nothing else there (#50 CI simulation) — Pristine-tree comparisons allow exactly that empty mount point.
- 2026-11-03 — SonarJS `recommended` reports TODO/FIXME comment tags as errors, and ESLint applies a blanket `eslint-disable` to every rule, including a custom rule that reports the directive itself (#50) — Use neutral words in fixture comments; make blanket directives fail by stopping the lint run.
- 2026-11-03 — #50 consumed about 1.9M sub-agent tokens before code review: seven Fable spec rounds and one author resumed repeatedly (586k cumulative context) — Apply the AGENTS token-economy override: Opus-high iterations, a single Fable decision pass, fresh authors per phase, a 600k soft budget per ticket with stop-and-report.
- 2026-11-03 — A Vitest `beforeEach`/`afterEach` arrow that returns a mock (for example `() => vi.mocked(fn).mockClear()`) makes Vitest call it as a cleanup hook (#12 sessions test) — Wrap hook bodies in braces.
- 2026-11-03 — Node `writeHead(status, headers)` followed by `end(body)` adds no `Content-Length`, so the response is chunked (#12 adapter) — Set `Content-Length` explicitly when an adapter writes the head itself.
- 2026-11-03 — `node scripts/x.ts` cannot import `src/**/*.ts`: the sources import each other with `.js` specifiers and Node does not remap them (#12 composition) — Load compiled `dist/` modules at run time from a script, and keep type-only imports from `src/`.
