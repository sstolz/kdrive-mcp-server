## Rule

For an authorized identity the proxy creates an authorization code (32 random bytes) valid for 60 seconds, bound to the client ID, the exact `redirect_uri` of the authorization request, the `code_challenge`, the `resource` and the identity, and produces a client redirect with `code`.

## Rationale

Short, one-use codes bound to client, redirect, PKCE and resource limit the value of a leaked code. Source: [F-010 v1](../features/F-010-oauth-proxy.md), AC-13, AC-16.

## Examples

- **Given** a code issued at t
  **When** it is redeemed at t + 59.999 s
  **Then** tokens are issued.
- **Given** a code issued at t
  **When** it is redeemed at t + 60 s
  **Then** 400 `invalid_grant`.
