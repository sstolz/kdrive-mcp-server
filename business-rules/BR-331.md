# BR-331 — Summary request shape

## Rule

Every request URL is built as `new URL("api/<fixed path>", base)`, where `base` is the URL accepted by `validHost` with a trailing `/` ensured and the fixed path is relative (no leading `/`), so a host path prefix such as `/sonar` is preserved; query values are encoded only through `URLSearchParams`. Each request uses `redirect: "error"`, sends `Authorization: Basic base64(token + ":")` and no other credential, and has its own 15 s timer that covers the headers and the whole body.

## Rationale

Keeps the token on the validated host only and the host path prefix intact (T1, T4). Source: [F-022 v1](../features/F-022-sonar-gate-summary.md).

## Examples

- **Given** the host `https://example.test/sonar` and a `ceTaskId` `a&b#c/d`
  **When** the task request is built
  **Then** its URL is `https://example.test/sonar/api/ce/task?id=a%26b%23c%2Fd`, with `redirect: "error"` and only the Basic `Authorization` header
- **Given** a task request that never answers
  **When** 15 s pass
  **Then** the request is aborted and the task stage line prints
