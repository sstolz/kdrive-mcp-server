# BR-016 — Locally validated single executable

Statement preserved from [F-002 v1](../features/history/F-002-v1.md); accepted under [F-002 v2](../features/F-002-configuration.md). The v2 CLI diagnostic phase ordering applies without rewriting this rule.

## Rule

**v3 (F-024 v2, #2, accepted on main `163e701`; the active rule).** v2 holds with these changes: the package name is `@sstolz/kdrive-mcp-server`; `bin` is exactly `{"kdrive-mcp-server": "dist/cli.js"}`, so the command stays `kdrive-mcp-server`; `--help` usage still starts `Usage: kdrive-mcp-server`, `--version` still prints the package version, the MCP server-info name stays `kdrive-mcp-server`, and the kDrive User-Agent product token stays `kdrive-mcp-server/<version>`; `repository` is exactly `{"type": "git", "url": "https://github.com/sstolz/kdrive-mcp-server.git"}` (npm rejects a provenance publish whose `repository.url` does not match the source repository).

**v2 (F-014 v1, accepted; superseded by v3).** Standalone `--version` keeps v1 behaviour. `--help` keeps v1 behaviour except that the two lines starting `Validate local configuration;` and `Injected stdio modules exist;` are replaced by the single line `Serve kDrive over stdio or HTTP after production preflight.` Ordinary invocation loads the local configuration, runs production preflight through the adapter, and starts the selected stdio or HTTP runtime with the production adapter; any configuration or preflight failure prints one sanitized `Configuration error [<code>] (<setting>).` line to stderr and exits 1; the text `runtime is not implemented yet` no longer exists.

v1 below was superseded by v2 (accepted on main `2a9c1e3`), itself superseded by v3.

### v1 (accepted)

Preserve package name `kdrive-mcp-server`, ESM,
Node `>=26.13.0 <27`, executable `dist/cli.js`, and its single binary name.
Standalone `--version` prints the package version plus LF and exits 0;
standalone `--help` prints current usage plus LF and exits 0. Both ignore
deployment environment and perform no configuration, credential or network
I/O. Mixed help/version arguments are invalid. Ordinary invocation follows
BR-017–BR-028; configuration failure prints one sanitized diagnostic to stderr
and exits 1. Successful local preparation selects the transport, prints
`Configuration validated locally; <stdio|http> runtime is not implemented yet.`
plus LF to stderr, and exits 1. It opens no listener, sends no protocol output,
invokes no production preflight, and never implies remote validation. Stdout
remains empty on every ordinary invocation.

The source specification's inventory, bounds, grammars, auth matrix, credential
contract, error mapping and preflight port supply the normative details for
this statement; this record does not redefine those tables.

## Rationale

Preserve honest executable behavior while configuration precedes runtime delivery.

## Examples

These examples illustrate the accepted rule; they do not replace the source specification or claim a new test execution. Unless a scenario overrides them, local-loader fixtures use explicit drive `7` and token `SYNTHETIC_TOKEN`, with no deployment state. Each verification names one existing test case or table row.

- **Given** the executable built from package version `0.1.0` and sole argument `--version`.
  **When** the executable runs.
  **Then** it writes `0.1.0\n` to stdout, leaves stderr empty and exits 0.
  Verified by: [`returns expected output for $args`](../tests/cli.test.ts), row `args: ["--version"]`.

- **Given** sole argument `--help` and hostile environment `KDRIVE_TOKEN_FILE=/DO_NOT_READ_CANARY`, `KDRIVE_UNKNOWN=CANARY`, `OAUTH_UNKNOWN=CANARY`.
  **When** the executable runs.
  **Then** it exits 0, leaves stderr empty and does not expose `CANARY`.
  Verified by: [`ignores hostile deployment environment for %s`](../tests/cli.test.ts), row `--help`.

- **Given** arguments `--help --version`.
  **When** the executable runs.
  **Then** stdout is empty, stderr is `Configuration error [INVALID_VALUE] (cli).\n` and exit is 1.
  Verified by: [`returns expected output for $args`](../tests/cli.test.ts), row `args: ["--help", "--version"]`.

- **Given** no arguments, `KDRIVE_ID=7` and `KDRIVE_TOKEN=SYNTHETIC_CLI`.
  **When** the executable completes local preparation.
  **Then** stdout is empty, stderr is `Configuration validated locally; stdio runtime is not implemented yet.\n` and exit is 1; no listener or protocol starts.
  Verified by: [`only validates local %s without listener or protocol`](../tests/cli.test.ts), row `stdio`.

- **Given** arguments `--http --insecure-no-auth`, `KDRIVE_ID=7` and `KDRIVE_TOKEN=SYNTHETIC_CLI`.
  **When** the executable completes local preparation.
  **Then** stdout is empty, stderr is `Configuration validated locally; http runtime is not implemented yet.\n` and exit is 1.
  Verified by: [`only validates local %s without listener or protocol`](../tests/cli.test.ts), row `http`.

- **Given** no arguments or configured drive identifiers.
  **When** the executable runs.
  **Then** stdout is empty, stderr is `Configuration error [MISSING_REQUIRED] (driveIds).\n` and exit is 1.
  Verified by: [`returns expected output for $args`](../tests/cli.test.ts), row `args: []`.
