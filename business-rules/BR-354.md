# BR-354 — Release documentation with the scoped name

## Rule

README.md names the packed tarball only as `./artifacts/sstolz-kdrive-mcp-server-<version>.tgz` (current version, leading `./`) and contains `npm install -g @sstolz/kdrive-mcp-server@beta`; no tracked file outside `features/`, `business-rules/` and CHANGELOG.md contains `artifacts/kdrive-mcp-server-`; SPEC.md's `npx` lines read `npx @sstolz/kdrive-mcp-server`. docs/publishing.md has no "Pending change" paragraph, marks the npm name as in use, states that `latest` points at the deprecated placeholder `0.0.0-placeholder.0` until 1.0.0 and that users install `@beta` or an exact version (never that `latest` points to the first beta), and its "Release workflow" section lists the preconditions in the order P-0, P-1, P-4, P-2, P-5, P-3 with the P-0 commands verbatim (ending with `npm logout`), states that P-3 is done after the first image push and verified by `read-back`, that the release is dispatched from `main` while the release commit is `main`'s HEAD, that a green real `dry_run=true` dispatch of the same version and commit is required and its run link recorded before any `dry_run=false` dispatch, and gives the D-8 recovery cases of the source specification (read-back failed; `npm publish` reported a failure; image pushed but npm not published; second approval expired; image push failed with or without the version in GHCR; delete and re-dispatch only while the release commit is `main`'s HEAD).

## Rationale

Users and the owner need one accurate install path and one release procedure, including what to do after a partial failure, before anything is published. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** README.md
  **When** the documentation test runs
  **Then** it contains `./artifacts/sstolz-kdrive-mcp-server-0.1.0.tgz` and `npm install -g @sstolz/kdrive-mcp-server@beta`
- **Given** a tracked file outside the excluded records containing `artifacts/kdrive-mcp-server-`
  **When** the documentation test runs
  **Then** it fails
