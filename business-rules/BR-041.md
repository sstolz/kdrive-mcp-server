# BR-041 — Cumulative levels

## Rule

Read operations require level `read`, mutations require at least `write`, and sharing operations require `share`; no feature switch can increase the configured cumulative level.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Ensure feature switches cannot raise read/write/share authority.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** read mode with shared/public-link switches enabled, **When** replacing file 13, **Then** the operation is denied.
- **Given** share mode with public links enabled, **When** sharing file 13 by link, **Then** the operation is permitted.

Both examples map to the test or parameter rows named below.
