## Rule

Normalized received capabilities set `read` to the provider `can_read === true`, set `list` and `search` to `can_read === true` on a directory, and set every mutation predicate of the F-004 matrix to `false`. The received list envelope sets `discover:true` only on a complete `shared_with_me` page.

## Rationale

Received items must stay read-only until share writes are qualified (#17–#20). Source: [F-014 v1](../features/F-014-production-kdrive-adapter.md).

## Examples

- **Given** a received directory with `can_read` true and `can_write` true
  **When** it is normalized
  **Then** `read`, `list` and `search` are true and every mutation predicate is false.
- **Given** a `shared_with_me` page with `has_more` true and no cursor
  **When** received `list` runs
  **Then** it returns `{status:"incomplete"}` without `discover`.
