# BR-017 — Deterministic configuration precedence

Statement preserved from [F-002 v1](../features/history/F-002-v1.md); accepted under [F-002 v2](../features/F-002-configuration.md). The v2 CLI diagnostic phase ordering applies without rewriting this rule.

## Rule

Parse only the exact source/option inventory below. Select each
effective setting in order CLI > environment > explicitly selected YAML >
default; replace complete list values rather than merging them. Select the
inline/file credential pair atomically at the highest source supplying either
member; both members at that same source are an error. Apply all value and
cross-field checks to the resulting effective configuration before reading
any selected credential file. Lower-priority values do not reappear when a
higher-priority value is empty or invalid. Invalid CLI structure, unknown
reserved environment names, malformed YAML and unknown YAML keys always fail,
even if a higher source would otherwise replace their values.

The source specification's inventory, bounds, grammars, auth matrix, credential
contract, error mapping and preflight port supply the normative details for
this statement; this record does not redefine those tables.

## Rationale

Avoid permissive values leaking through lower-priority sources or merged lists.

## Examples

These examples illustrate the accepted rule; they do not replace the source specification or claim a new test execution. Unless a scenario overrides them, local-loader fixtures use explicit drive `7` and token `SYNTHETIC_TOKEN`, with no deployment state. Each verification reference identifies one existing test case or table row.

- **Given** valid synthetic configuration with environment `KDRIVE_MCP_MODE=invalid ignored` and CLI `--mode=share`.
  **When** `loadConfiguration` selects the effective mode.
  **Then** mode is `share`.
  Verified by: [`normalizes inventory %s from every supported source`](../tests/config.test.ts), row `mode`, CLI assertion.

- **Given** valid synthetic configuration with environment `KDRIVE_MCP_MODE=share` and no CLI mode.
  **When** `loadConfiguration` selects the effective mode.
  **Then** mode is `share`.
  Verified by: [`normalizes inventory %s from every supported source`](../tests/config.test.ts), row `mode`, environment assertion.

- **Given** valid synthetic configuration without CLI/environment mode and explicitly selected YAML `mode: "share"`.
  **When** `loadConfiguration` selects the effective mode.
  **Then** mode is `share`.
  Verified by: [`normalizes inventory %s from every supported source`](../tests/config.test.ts), row `mode`, YAML assertion.

- **Given** YAML `tokenFile: /ignored` and `deny: [/old]`, environment inline token plus `KDRIVE_TOKEN_FILE=/ignored-env` and `KDRIVE_MCP_DENY=/env`, and CLI `--token-file /chosen --deny ''`.
  **When** configuration loads using the injected reader.
  **Then** the token is `SYNTHETIC_CLI`, deny is `[]`, and the only reads are `/work/settings.yaml` then `/chosen`; the higher-source file replaces the complete lower-source credential pair.
  Verified by: [`replaces whole lists and atomically selects credential sources without reading losers`](../tests/config.test.ts), successful source-selection assertion.

- **Given** environment `KDRIVE_TOKEN=SYNTHETIC_TOKEN` and present-empty `KDRIVE_TOKEN_FILE=''` at that same source.
  **When** configuration loads.
  **Then** it rejects with `{code: CONFLICTING_SETTINGS, setting: token}`.
  Verified by: [`replaces whole lists and atomically selects credential sources without reading losers`](../tests/config.test.ts), empty token-file conflict assertion.

- **Given** environment `KDRIVE_MCP_MODE=''`, no CLI mode and a lower YAML argument `mode: read` that is not explicitly selected.
  **When** configuration loads.
  **Then** it rejects with `{code: INVALID_VALUE, setting: mode}`; empty is present and no lower value is restored.
  Verified by: [`replaces whole lists and atomically selects credential sources without reading losers`](../tests/config.test.ts), empty mode assertion.

- **Given** arguments `--mode read --mode share`.
  **When** CLI structure is validated.
  **Then** it rejects with `{code: DUPLICATE_OPTION, setting: cli}`.
  Verified by: [`maps CLI structure case %#`](../tests/config.test.ts), row `--mode read --mode share`.

- **Given** arguments `--mode --roots 7:1`.
  **When** CLI structure is validated.
  **Then** it rejects with `{code: INVALID_VALUE, setting: mode}` because the recognized next option is not a mode value.
  Verified by: [`maps CLI structure case %#`](../tests/config.test.ts), row `--mode --roots 7:1`.

- **Given** 129 arguments each equal to `x`.
  **When** global argv budgets are checked.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: cli}` before unknown-option scanning.
  Verified by: [`maps CLI structure case %#`](../tests/config.test.ts), row `Array.from({length: 129}, () => "x")`.

- **Given** arguments `--bad`, 65,536 `x` characters and 65,536 `y` characters, totaling 131,077 UTF-8 bytes.
  **When** global argv budgets are checked.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: cli}` before the unknown option.
  Verified by: [`applies byte/count limits before content failures within effective values`](../tests/config.test.ts), global argv overflow assertion.

- **Given** a `--roots` value consisting of 128 entries `7:/000` through `7:/127`, each suffix padded with 505 `x` characters and one extra `x` on the first entry, totaling exactly 65,536 UTF-8 value bytes.
  **When** the value is supplied as either `--roots VALUE` or `--roots=VALUE`.
  **Then** all 128 roots load successfully; the complete `--roots=VALUE` argument has no separate 65,536-byte ceiling.
  Verified by: [`allows exactly 65536 value bytes in either form and bounds only recognized values`](../tests/config.test.ts), exact roots-value assertion.

- **Given** that same 65,536-byte roots value with one extra `x`, supplied as `--roots=VALUE`.
  **When** recognized raw CLI value budgets are checked.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: roots}`.
  Verified by: [`allows exactly 65536 value bytes in either form and bounds only recognized values`](../tests/config.test.ts), adjacent roots-value assertion.

- **Given** `--mode=` followed by exactly 65,536 `x` characters.
  **When** CLI structure and raw budgets pass and mode content is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: mode}`, because the bounded value is not an allowed mode.
  Verified by: [`allows exactly 65536 value bytes in either form and bounds only recognized values`](../tests/config.test.ts), exact mode-value assertion.

- **Given** `--unknown` followed by `--mode=` plus 65,537 `x` characters, within global argv budgets.
  **When** CLI structure is validated before recognized raw-value budgets.
  **Then** it rejects with `{code: UNKNOWN_OPTION, setting: cli}`.
  Verified by: [`maps structure and raw budgets case %#`](../tests/config.test.ts), row `["--unknown", "--mode=" + oversized]`.

- **Given** a sole `--mode=` value of 65,537 `x` characters.
  **When** recognized raw CLI value budgets are checked.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: mode}`.
  Verified by: [`maps structure and raw budgets case %#`](../tests/config.test.ts), row `["--mode=" + oversized]`.

- **Given** `--help` followed by `--mode=` plus 65,537 `x` characters, within global argv budgets.
  **When** information-command mixing is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: cli}` before the raw mode-value limit.
  Verified by: [`maps structure and raw budgets case %#`](../tests/config.test.ts), row `["--help", "--mode=" + oversized]`.

- **Given** environment `OAUTH_UNKNOWN=CANARY` and `KDRIVE_MCP_MODE=x`.
  **When** environment structure is checked.
  **Then** it rejects with `{code: UNKNOWN_SETTING, setting: environment}` before validating the mode.
  Verified by: [`checks structures before winning values and reads no implicit files`](../tests/config.test.ts), reserved-name assertion.

### Additional boundary coverage

These boundary cases exercise the existing accepted F-002 v2 behavior through injected synthetic inputs. Their named tests are implemented in the linked test file.

- **Given** exactly 128 argv elements, each the single ASCII character `x`, and no configuration source reads.
  **When** configuration loading checks global budgets and then CLI structure.
  **Then** it rejects with `{code: UNKNOWN_OPTION, setting: cli}`; 128 elements pass the count budget but do not make unknown arguments valid.
  Verified by: [`TestBR017_ArgvCount128ReachesStructure — BR-017 v1`](../tests/config-selection-boundaries.test.ts).

- **Given** one argv element containing exactly 131,072 ASCII `x` characters.
  **When** configuration loading checks global budgets and then CLI structure.
  **Then** it rejects with `{code: UNKNOWN_OPTION, setting: cli}`; the exact total-byte budget passes and no separate unknown-argument byte ceiling applies.
  Verified by: [`TestBR017_ArgvTotal131072ReachesStructure — BR-017 v1`](../tests/config-selection-boundaries.test.ts).

- **Given** one argv element containing exactly 131,073 ASCII `x` characters.
  **When** configuration loading checks global budgets.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: cli}` before CLI structure.
  Verified by: [`TestBR017_ArgvTotal131073FailsBudget — BR-017 v1`](../tests/config-selection-boundaries.test.ts).

- **Given** environment `KDRIVE_MCP_ROOTS` containing entries `7:/000` through `7:/127`, each suffixed with 505 ASCII `x` characters and one extra `x` on the first entry, totaling exactly 65,536 UTF-8 value bytes.
  **When** configuration loading checks the raw environment value and parses the roots.
  **Then** it accepts all 128 roots for explicit drive `7`.
  Verified by: [`TestBR017_EnvironmentRawValue65536Accepted — BR-017 v1`](../tests/config-selection-boundaries.test.ts).

- **Given** that same 65,536-byte environment roots value with one extra trailing ASCII `x`.
  **When** configuration loading checks raw environment value budgets.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: roots}`.
  Verified by: [`TestBR017_EnvironmentRawValue65537Rejected — BR-017 v1`](../tests/config-selection-boundaries.test.ts).
