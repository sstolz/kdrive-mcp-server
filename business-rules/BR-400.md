# BR-400 — Proxy page stylesheet

## Rule

The stylesheet is one fixed string (identical in every response) that: (1) declares exactly these colour tokens as CSS custom properties in `:root` (light): `--bg --surface --fg --muted --link --code-fg --code-bg --primary-fg --primary-bg --secondary-fg --secondary-bg --border --focus`, each a `#rrggbb` value, redeclares every one of them inside `@media (prefers-color-scheme: dark)`, contains no other colour literal (every other colour use is `var(--…)`), and sets `color-scheme: light dark`; the page uses `--bg` behind the header, footer and page, `--surface` behind the main card, `--code-bg` behind `code`, and the primary/secondary tokens for the Approve/Deny buttons; (2) uses a system font stack only and contains no `@import`, `@font-face`, `url(` or `image-set(`; (3) contains no `transition`, `animation` or `@keyframes` (nothing moves, so reduced motion holds without a query); (4) gives `:focus-visible` on buttons and links an `outline` of at least 2px solid in a declared colour; (5) wraps long values (`overflow-wrap: anywhere` on `code`), limits the content width with a `max-width` in `rem` or `%`, sets `box-sizing: border-box` on every element, and sets no `width` or `min-width` other than `%` or `auto`; (6) reaches, in both themes, a WCAG 2.x contrast ratio of at least 4.5:1 for each of these pairs: `--fg`/`--bg`, `--fg`/`--surface`, `--muted`/`--bg`, `--muted`/`--surface`, `--link`/`--bg`, `--code-fg`/`--code-bg`, `--primary-fg`/`--primary-bg`, `--secondary-fg`/`--secondary-bg`; and at least 3:1 for `--focus`/`--bg`, `--focus`/`--surface` and `--border`/`--surface`.

## Rationale

A finished, readable look in light and dark themes without any external resource or motion, with contrast that meets WCAG 2.x AA. Source: [F-030 v1](../features/F-030-oauth-proxy-page-design.md).

## Examples

- **Given** the stylesheet constant
  **When** the test parses its light and dark tokens
  **Then** the token set is exactly the BR-400 one, every value is `#rrggbb` and every listed pair meets 4.5:1 (text) or 3:1 (focus, border) in both themes
- **Given** the stylesheet constant
  **When** the test scans it
  **Then** it holds no `@import`, `@font-face`, `url(`, `transition` or `animation`, and no `width` other than `%` or `auto`
