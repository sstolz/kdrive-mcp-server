## Rule

Authenticated MCP requests are limited per identity to 120 per 60-second window. A refused request yields HTTP-layer error 429 `rate_limited` with `Retry-After`, after authentication and before any body read.

## Rationale

A per-identity window bounds a runaway agent without a shared lockout. Source: [F-012 v1](../features/F-012-authenticated-http.md), AC-10.

## Examples

- **Given** identity A sent 120 authenticated requests within 60 seconds
  **When** it sends the 121st
  **Then** 429 `rate_limited` with `Retry-After`.
- **Given** identity B in the same period
  **When** it sends one request
  **Then** it is not refused.
