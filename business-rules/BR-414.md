# BR-414 — Stream decoding

## Rule

Only the streams BR-412, BR-413, BR-416, BR-417, BR-419 and BR-420 need are decoded; any other stream is framed by its `/Length` and never decoded, whatever its filter. A needed stream has no filter, or `/FlateDecode` given as a name or a one-element array, with optional `/DecodeParms` (a dictionary, or a one-element array holding one) whose `/Predictor` is 1 or 10–15, `/Colors` 1–4, `/BitsPerComponent` 8 and `/Columns` 1–65,536; PNG rows are undone with each row's own tag and the predicted data is a whole number of rows. Each needed stream is decoded once per invocation and its decoded length counts once against B with the F-009 inflate rules (`maxOutputLength` set to the remaining B, `rejectGarbageAfterEnd`), with two exceptions. A Flate inline image (BR-416) is inflated from the rest of its content stream with `maxOutputLength` set to the smaller of its computed size and the remaining B and without `rejectGarbageAfterEnd`, since the content after its data is not garbage; its data length is the number of input bytes the inflate consumed up to the end of the zlib stream. A Type 1 program (BR-420) takes no `/DecodeParms` and is inflated by a streaming inflate that stops as soon as it has produced `/Length1` bytes and reads no further input; a `/Length1` over the remaining B refuses as `LIMIT_EXCEEDED` before inflating, a program whose output (or unfiltered data) ends before `/Length1` bytes refuses as `CONTENT_UNAVAILABLE`, and the `/Length1` bytes count against B.

## Rationale

Images and font programs use filters text never needs; not decoding them removes their decoders and their budget. Flate with PNG predictors covers the cross-reference and content streams of common generators (F-034 S04, S05). Source: [F-034 v1](../features/F-034-pdf-extraction-profile.md).

## Examples

- **Given** Flate content with predictor 12 whose inflated bytes bring the decoded total to exactly B
  **When** page 1 is read
  **Then** its text
- **Given** the same content bringing the decoded total to B + 1 bytes
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js
- **Given** a predictor with `/Columns` 65,536 and `/Colors` 4
  **When** page 1 is read
  **Then** its text
- **Given** a predictor with `/Columns` 65,537
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js
- **Given** a page that also draws a `DCTDecode` image whose data is not a JPEG
  **When** page 1 is read
  **Then** its text, the image never decoded
- **Given** a Type 1 `FontFile` whose inflated output is shorter than its `/Length1`
  **When** page 1 is read
  **Then** `CONTENT_UNAVAILABLE` before PDF.js, when a shown code needs its built-in encoding
