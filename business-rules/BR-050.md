# BR-050 — Recipient-path effects

## Rule

Every affected current, original and resulting received-share path passes the existing deny matcher in the recipient namespace, using the F-003 operation-effect and complete descendant-proof requirements.

The detailed frozen evidence, capability, cache and effect contracts in
[F-004 v1](../features/F-004-received-share-policy.md) are normative.

## Rationale

Deny rules must cover every affected recipient-visible path.
