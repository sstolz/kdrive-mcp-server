# BR-334 — Quality Gate condition lines

## Rule

After a successful conditions stage, the summary prints `Quality Gate summary: <projectKey> status <projectStatus.status>`, then one line `- condition <metricKey> <comparator> <errorThreshold>: actual <actualValue>` per condition whose status is `ERROR`, at most 20, in server order, followed by `- <N> more conditions not shown` when more exist. The optional fields `comparator`, `errorThreshold` and `actualValue` print `-` when absent or not a string.

## Rationale

Shows which conditions failed the gate, bounded (D-6). Source: [F-022 v1](../features/F-022-sonar-gate-summary.md).

## Examples

- **Given** a project status `ERROR` with conditions `new_violations` `ERROR` (GT 1, actual 2) and `coverage` `OK`
  **When** the summary prints
  **Then** `Quality Gate summary: kdrive-mcp-server status ERROR` and `- condition new_violations GT 1: actual 2` only
- **Given** 21 `ERROR` conditions, the first without `comparator`
  **When** the summary prints
  **Then** 20 condition lines, the first `- condition metric_1 - 1: actual 2`, then `- 1 more conditions not shown`
