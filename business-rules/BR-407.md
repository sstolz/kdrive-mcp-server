# BR-407 — Message catalogue

## Rule

The fixed texts of the pages come from one catalogue object per language, `MESSAGES.en` and `MESSAGES.fr`, both typed by one `Messages` type so that a missing or extra key fails `tsc`; the error sentences are a nested object keyed by every `ErrorPage` kind. The English values are the BR-399/BR-402/BR-403/BR-129/BR-393 texts, the French values are those of the F-031 "French texts" table, byte for byte (a U+00A0 no-break space before `:`). No catalogue value contains `<`, `>`, `&` or `"`, and no French value equals its English value. Dynamic values (`clientName`, `clientId`, `cimd.host`, `redirectUri`, `resource`, `action`, `consentId`, the switcher query) are never translated and are HTML-escaped in both languages.

## Rationale

One typed catalogue keeps both languages complete and the security texts equivalent, with no i18n dependency (F-031 D-6). Source: [F-031 v1](../features/F-031-oauth-proxy-page-languages.md).

## Examples

- **Given** the two catalogues
  **When** their key sets are compared
  **Then** they are equal, `error` included
- **Given** an object missing one key typed as `Messages`
  **When** `tsc` runs
  **Then** it is rejected (the `@ts-expect-error` line stays valid)
