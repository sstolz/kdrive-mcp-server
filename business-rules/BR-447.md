# BR-447 — Process stream ownership

## Rule

Built-in process stdout and stderr use one permanent, idempotently installed error listener per stream identity before their first built-in write. Owners are resolved at call time through process getters and shared through a WeakMap. Production dependencies install both before returning; import alone installs neither. Owners never remove themselves, end or destroy streams, retry or recursively log. Injected owned streams retain transport ownership and acquire no process-lifetime listener.

## Rationale

Asynchronous process stream errors can outlive transport listeners and detached extraction sessions.

## Examples

- **Given** fresh process stream objects
  **When** productionDependencies is called repeatedly
  **Then** each stream has exactly one owner listener. Maps to `TestBR447_TestBR448_AC06_permanent_stderr_owner`.
- **Given** an owned injected output
  **When** the owned session closes
  **Then** its transport listener is removed and no permanent listener was installed. Maps to `TestBR447_TestBR448_AC06_permanent_stderr_owner`.
