# BR-262 — One mutate call and the gate result envelope

## Rule

A call to one of the five tools makes exactly one navigation `mutate` call with the tool name, the built operation, the session identity, the call signal and no payload, and returns one text content item holding the JSON of the gate result (BR-255), with `isError` false only when `result` is `succeeded`.

## Rationale

The client sees the exact gate classification, including `uncertain`, and nothing else. Source: [F-017 v1](../features/F-017-controlled-tree-mutations.md).

## Examples

- **Given** a gate result `succeeded`
  **When** `kdrive_trash` returns
  **Then** one text item holds that JSON and `isError` is false
- **Given** a gate result `uncertain`
  **When** `kdrive_trash` returns
  **Then** one text item holds that JSON and `isError` is true
