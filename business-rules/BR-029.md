# BR-029 — Trust successful preflight

## Rule

A policy decision uses only a successful F-002 resolved configuration and evidence acquired by its injected evidence dependency for that decision; caller assertions of ancestry, paths or completeness cannot confer authority.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Prevent callers from substituting configuration or evidence authority.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** unresolved local configuration, **When** constructing the policy, **Then** construction throws and no evidence is requested.
- **Given** successful preflight for root 7:10 and live file 13 under it, **When** dispatching read 13, **Then** one protected execution occurs.

Both examples map to the test or parameter rows named below.
