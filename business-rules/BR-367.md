# BR-367 — Endpoint overrides refused in CI

## Rule

`scripts/release.ts` reads `RELEASE_GITHUB_API_URL`, `RELEASE_NPM_REGISTRY_URL` and `RELEASE_GHCR_URL` (defaults `https://api.github.com`, `https://registry.npmjs.org`, `https://ghcr.io`) for test doubles only. When `GITHUB_ACTIONS` is `true` and any override is set, every mode prints only `release: endpoint override refused in CI` to stderr and exits 2 before any request or command.

## Rationale

Doubles make the scripts testable, but a real run can never be pointed at another endpoint. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** `GITHUB_ACTIONS=true` and `RELEASE_NPM_REGISTRY_URL` set
  **When** each mode runs
  **Then** it prints only the refusal, exits 2 and the doubles record no request
