# BR-011 — Mandatory CI and trusted conditional analysis

## Rule

CI runs for every main PR/push without path filters, with stable
lint/format/typecheck/test/build jobs, the same Docker Make setup and each gate.
Test builds before coverage; build checks packing. Failures fail jobs. Use
read-only contents permissions, pinned Actions, no publication/release/tag path.
Optional Sonar follows all gates only for explicitly enabled trusted-main
push/manual events; PR/forks never get the token or upload. Missing config,
network, timeout or bad gate fails analysis. Serialize each project and configure
no PR/branch analysis or decoration.

## Rationale

enforce the shared local contract without exposing analysis credentials.
