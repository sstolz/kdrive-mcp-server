## Rule

The `smoke` stage adds only `scripts/http-acceptance.ts` at `/app/scripts/http-acceptance.ts` (owned by root, not writable by UID 1000), sets `ENTRYPOINT ["node", "/app/scripts/http-acceptance.ts"]` and keeps `USER 1000:1000`. The smoke runner overrides that entrypoint only to prepend the BR-180 secret generation and then `exec`s the same command.

## Rationale

Smoke tests exercise the real HTTP layer of the runtime image without adding a production code path. Source: [F-013 v1](../features/F-013-http-image.md).
