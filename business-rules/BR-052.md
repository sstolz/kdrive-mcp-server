# BR-052 — Fresh mutation evidence

## Rule

Each mutation invocation obtains a new complete received-share list and fresh ancestry, paths and capabilities for every affected identity without using a previous invocation's evidence.

The detailed frozen evidence, capability, cache and effect contracts in
[F-004 v1](../features/F-004-received-share-policy.md) are normative.

## Rationale

Writes cannot use a prior decision's membership or capability authority.

## Examples

These are synthetic injected examples, not provider observations.

- **Given** a successful replace on8:24 followed by replace=false, **When** replacing8:24 again, **Then** the fresh predicate denies execution.
- **Given** two consecutive permitted replace requests, **When** authorizing each request, **Then** each invocation reloads the complete received list.

Each example maps to the named parameter row/group below, in the same order.
