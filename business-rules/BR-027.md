# BR-027 — Stable redacted configuration diagnostics

Source: [F-002 v1](../features/history/F-002-v1.md), BR-027, frozen
2026-11-01 21:18:28 UTC after fresh independent approval.

## Rule

Report only stable error codes and canonical setting names from
the error contract below. Never include input values, credentials, file paths,
YAML excerpts, parser/file/adapter exception text or configuration dumps in
diagnostics. Sanitize injected dependency failures before they cross the
configuration boundary, including split/multiple validation failures. The CLI
emits only the first deterministic error and no stack trace.

The source specification's inventory, bounds, grammars, auth matrix, credential
contract, error mapping and preflight port supply the normative details for
this statement; this record does not redefine those tables.

## Rationale

Configuration errors must be actionable without exposing source values or dependency messages.

the listed source/dependency failure, **When** configuration loading, preflight
or the diagnostic executable handles it, **Then** only the stated diagnostic
