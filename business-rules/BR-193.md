## Rule

Each JSON request completes, body included, within 5,000 ms; each download open reaches its final response headers, both hops included, within 5,000 ms; each body `read` settles within 5,000 ms; an aborted content `signal` destroys the socket at once; on any of these the adapter rejects with the unbranded failure of BR-196.

## Rationale

Signal-less policy ports and stalled peers must not hold sockets or invocations open indefinitely. Source: [F-014 v1](../features/F-014-production-kdrive-adapter.md).

## Examples

- **Given** a JSON body that stalls after the headers
  **When** 4,999 ms pass
  **Then** the call is still pending.
- **Given** the same stall
  **When** 5,000 ms pass
  **Then** the call rejects `READ_UNAVAILABLE`, the socket is destroyed and no timer remains.
