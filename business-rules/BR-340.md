# BR-340 — Development docs for the summary

## Rule

`docs/development.md`, "Conditional remote analysis", lists the summary line formats, the degraded issues line, the token upgrade path (user token with Browse, no code change), and states that issue lines reflect the project's current open issues, which for `kdrive-mcp-server-pr` may include another pull request's latest analysis.

## Rationale

Agents and maintainers must read the summary and know the degraded mode and its fix. Source: [F-022 v1](../features/F-022-sonar-gate-summary.md).

## Examples

- **Given** `docs/development.md`
  **When** the reader opens "Conditional remote analysis"
  **Then** it lists the summary line formats, the degraded issues line and the user-token upgrade path
- **Given** the same section
  **When** the reader looks for the issue scope
  **Then** it states that issue lines may include another pull request's latest analysis for `kdrive-mcp-server-pr`
