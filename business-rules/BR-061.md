## Rule

Item navigation uses the configured default drive when its drive argument is omitted, catalogue omission enumerates configured drives, and an explicit drive never changes or falls back to the default.

## Rationale

An omitted or explicit drive must never silently select another drive. Source: [F-005 v1](../features/F-005-stdio-navigation.md), AC-03.

## Examples

- **Given** default drive 7 and file3 on both drives7 and9.
  **When** info omits drive_id.
  **Then** the item is from drive7.
- **Given** an explicit unknown drive12.
  **When** info requests file3.
  **Then** ACCESS_DENIED returns without ordinary protected port calls.
