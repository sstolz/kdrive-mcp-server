## Rule

The listener binds the effective `httpHost`/`httpPort` of F-002 (default `127.0.0.1:3000`, BR-024 v2). In insecure mode it binds literal `127.0.0.1` (BR-025 v2); after `listen` succeeds, an insecure listener whose bound address is not `127.0.0.1` is closed and `HttpStartupError` `INSECURE_BIND_REFUSED` is raised. A failed `listen` raises `HttpStartupError` `LISTEN_FAILED` without the system error text.

## Rationale

An insecure listener must never face the network, and a failed bind must not leak system text. Source: [F-012 v1](../features/F-012-authenticated-http.md), AC-02.

## Examples

- **Given** insecure mode with host `0.0.0.0` configured
  **When** `startHttpServer` binds
  **Then** the injected `listen` receives host `127.0.0.1`.
- **Given** an injected `listen` that reports address `0.0.0.0` in insecure mode
  **When** `startHttpServer` returns
  **Then** `INSECURE_BIND_REFUSED` is raised and the server is closed.
