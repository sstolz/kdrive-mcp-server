# BR-313 — OAuth proxy notes for the persistent state

## Rule

`docs/oauth-proxy.md` replaces "Restart and residual risks" with sections that state: what `OAUTH_STATE_FILE` persists and what a restart still loses; the file and directory requirements and the five startup codes with the operator action for each; the single-instance and local-file-system restriction; that replacing the signing key keeps refresh families valid while access tokens fail until refreshed; that the file and its directory are a credential store: anyone who can write either can add a client and a family for an allowlisted subject and obtain tokens after the next restart, and restoring an older copy brings back families revoked or rotated since, so the mount gets the same protection as the signing key and the file is never restored from a backup; that `<path>-journal` belongs to the store (it exists while the server runs and may remain after a crash) and is never deleted, moved or copied apart from the file; that deleting the file and its `<path>-journal` while the server is stopped revokes every client and family (every user logs in again); the operator action after `store_write_failed` (fix the cause, then restart; the revocation whose failed commit latched the store is lost at that restart, and replacing the file is the only way to be sure no revoked family returns, at the cost of a new login for every user); the operator action after a downgrade to an image without `OAUTH_STATE_FILE` (replace the file before upgrading again, or families from before the downgrade return); and the residual risks of D-9.

## Rationale

The operator must know what is persisted, what each startup code needs, and that the mount is a credential store. Source: [F-019 v1](../features/F-019-persistent-oauth-state.md).

## Examples

- **Given** the updated `docs/oauth-proxy.md`
  **When** the content test runs
  **Then** it states the credential-store warning, the delete-to-revoke-all action, the `store_write_failed` and downgrade actions and each `OAUTH_STATE_*` code
- **Given** the document without the credential-store warning
  **When** the content test runs
  **Then** it fails
