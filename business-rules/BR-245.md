## Rule

Admission refuses a run as `failed`, with zero records, zero policy calls and zero upstream attempts, with code `UNAVAILABLE` when the tool name is not one of the eight mutation tools of SPEC §6, the operation is not a valid F-003 mutation or share kind other than `batch`, its kind is not admitted for the tool by the admission table below, or no mutator is registered for its kind; with `ACCESS_DENIED` when the configured mode is `read`; and with `AUDIT_UNAVAILABLE` when the sink is latched or the gate is closed.

## Rationale

Only known tool/kind pairs with a registered mutator, in a write mode, with a working sink, may reach the policy. Source: [F-016 v1](../features/F-016-mutation-audit-gate.md).

## Examples

- **Given** `kdrive_rename` with a `move` operation
  **When** a run starts
  **Then** it is refused `UNAVAILABLE` with zero records and zero policy calls
- **Given** mode `read`
  **When** a run starts
  **Then** it is refused `ACCESS_DENIED`
