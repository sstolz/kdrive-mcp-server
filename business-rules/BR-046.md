# BR-046 — Bounded refusal diagnostics

## Rule

Refusals expose only the bounded diagnostic codes below and never include raw evidence, provider exceptions, credentials or paths.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Prevent an authorization failure from exposing upstream evidence or arbitrary errors.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** inspection rejects with a synthetic credential/path object, **When** dispatching a read, **Then** only ACCESS_DENIED is returned and toString is never called.
- **Given** that same evidence failure, **When** calling internal check, **Then** only EVIDENCE_UNAVAILABLE is returned.

Both examples map to the test or parameter rows named below.
