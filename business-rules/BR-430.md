# BR-430 — Static compact description metadata without behavior changes

## Rule

**v1 (F-042 v1, #42; accepted on main `3b035b8`)**

The F-042 description catalog consists only of fixed trusted server text and trusted numeric constants, meets the catalog byte budgets, and changes no non-description schema, protocol, validation or runtime behavior.

Source: [F-042 v1](../features/F-042-mcp-tool-descriptions.md), #42 decision.

## Rationale

Descriptions are instructions supplied by the server to clients. They must not contain configuration or provider-controlled content, consume an excessive context budget, or accidentally change the accepted input contract. The catalog's byte budgets are test assertions; they neither truncate descriptions nor make masked internal guards part of the published parameter contract.

## Examples

- **Given** two configurations with distinct instruction-like marker names and paths
  **When** tools/list runs before and after navigation
  **Then** descriptions are byte-identical, contain neither marker and listing makes no provider calls. Maps to `TestBR430_AC08_descriptions_are_static_and_compact`.
- **Given** the prior tools/list baseline with descriptions recursively removed
  **When** descriptions are added and removed again for comparison
  **Then** names, order, annotations and every remaining schema keyword equal the baseline. Maps to `TestBR430_AC07_only_description_metadata_changes`.
- **Given** a test helper with a 2048-byte tool description
  **When** its per-tool budget is checked
  **Then** it passes; 2049 bytes fails. A parameter/item description passes at 768 bytes and fails at 769; summed description bytes pass at 32768 and fail at 32769; serialized result bytes pass at 49152 and fail at 49153. Maps to `TestBR430_AC08_descriptions_are_static_and_compact`; these are test controls, not runtime rejections.
- **Given** the actual mutation-enabled catalog
  **When** all four budgets are measured
  **Then** each passes while every mandatory notice remains intact. Maps to the same test.
