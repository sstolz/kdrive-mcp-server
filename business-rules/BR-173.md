## Rule

`deps` runs `npm ci --omit=dev --omit=optional --ignore-scripts` from the lockfile with `--cache` set to a directory that the same `RUN` removes. `runtime` has no `RUN` that invokes `npm` and copies into `/app` only `dist/` (from `build`), `node_modules/` (from `deps`), `package.json`, `package-lock.json`, `LICENSE`, `NOTICE` and `README.md`. The runtime image contains no `/app/src`, `/app/tests`, `/app/scripts`, `/app/.git`, `/app/secrets`, `/app/.env*`, no `node_modules/typescript` or `node_modules/vitest`, no `node_modules/@napi-rs` directory and no `*.node` file under `/app/node_modules`. In the runtime image, `node --input-type=module -e "await import('/app/dist/extraction-pdf.js')"` exits 0.

## Rationale

A small, reproducible runtime without dev tooling, sources or native optional binaries; the build output is valid for both architectures. Source: [F-013 v1](../features/F-013-http-image.md).

## Examples

- **Given** a `COPY . .` added to `runtime`
  **When** the static policy runs
  **Then** it fails
- **Given** the built runtime image
  **When** `make image-smoke` runs the absence and import checks
  **Then** both exit 0
