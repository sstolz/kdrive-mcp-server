# BR-281 — One `mutate` call with the upload operation

## Rule

A valid call makes exactly one navigation `mutate` call with tool `kdrive_upload`, the operation `{kind:"upload-new", destination:{driveId, id:parent_id}, name}` when `overwrite` is `false`, or `{kind:"replace", target:{driveId, id:file_id}, destination:{driveId, id:parent_id}, name}` when it is `true`, the session identity, the call signal and the content bytes as payload; it returns one text content item holding the JSON of the gate result, with `isError` false only when `result` is `succeeded`.

## Rationale

The F-016 gate records and classifies every upload; the payload stays on the opaque channel and is never recorded. Source: [F-018 v1](../features/F-018-upload.md).

## Examples

- **Given** `overwrite:true`, `file_id` 6, `parent_id` 5
  **When** the call is valid
  **Then** the operation is `replace` with target 6 and destination 5
- **Given** a gate result `failed` 409
  **When** the tool returns
  **Then** one text item with that JSON and `isError` true
