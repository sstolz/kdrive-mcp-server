# BR-003 — Injected metadata dependency only

## Rule

the injected metadata adapter is the only data-access dependency.
`info` returns the result unchanged as `unknown` or propagates its rejection
unchanged without retry. Import and construction perform no I/O. No production
adapter is supplied.

## Rationale

keep the initial boundary testable and independent of transport/SDK.

## Examples

These concrete scenarios illustrate the unchanged rule and its boundaries; they are verification targets, not new test execution results or a replacement for the full contract.

| Example | Given                                                                                             | When                                                                  | Then                                                                                         |
| ------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| E-01    | **Given** a drive `101` client and adapter returning object `{id:11,nested:{label:"synthetic"}}`. | **When** `info(11)` is awaited.                                       | **Then** the exact same object is returned by identity; the sole adapter call is `(101,11)`. |
| E-02    | **Given** a drive `101` client whose adapter rejects with one synthetic Error object.             | **When** `info(11)` is awaited.                                       | **Then** the same Error object is propagated by identity after one call and no retry.        |
| E-03    | **Given** a fresh adapter spy.                                                                    | **When** clients for drives `101` and `202` are constructed.          | **Then** the adapter has zero calls.                                                         |
| E-04    | **Given** an isolated child with filesystem and network guards.                                   | **When** the metadata module is imported and a client is constructed. | **Then** the child exits successfully without filesystem or network I/O.                     |
