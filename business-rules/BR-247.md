## Rule

The final result of an upstream attempt follows the classification table below; a value the port returns outside its contract, or any thrown value other than the branded `not-sent` failure, is classified `uncertain`.

## Rationale

Only proven refusals count as `failed`; anything unproven must be verified (D-16-6). Source: [F-016 v1](../features/F-016-mutation-audit-gate.md).

## Examples

- **Given** an attempt answering 409
  **When** the run ends
  **Then** the result is `failed`/`UPSTREAM_REJECTED`
- **Given** an attempt answering 408 or throwing an object with `status:409`
  **When** the run ends
  **Then** the result is `uncertain`/`UPSTREAM_UNCERTAIN`
