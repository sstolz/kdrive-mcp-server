# BR-051 — Bounded list-only read cache

## Rule

Only complete validated received-share-list snapshots are cached across read invocations, and a read may use one only while elapsed monotonic time from acquisition start is nonnegative and strictly less than 60 seconds.

The detailed frozen evidence, capability, cache and effect contracts in
[F-004 v1](../features/F-004-received-share-policy.md) are normative.

## Rationale

Limit revocation lag while preserving fresh target proofs.

## Examples

These are synthetic injected examples, not provider observations.

- **Given** a complete list started at0ms and a read at59999ms, **When** reading child8:24, **Then** the list is reused and target evidence is freshly inspected.
- **Given** the same list and a read at60000ms, **When** reading child8:24, **Then** the list is freshly reloaded.
