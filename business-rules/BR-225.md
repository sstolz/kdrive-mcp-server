Timeouts unchanged, plus `privacy-scan` 20. (v2: label array `[self-hosted, linux, x64, kdrive-ci]` except `fork-refusal`, `audit` included.) The label array survives only in `runner-acceptance.yml` (BR-229 v2).

v2 (F-020 v1, #104; accepted on main `b6acf86`, 2026-11-11): v1 holds; `audit` runs on the label array, and the `timeout-minutes` table adds `audit` 20.
