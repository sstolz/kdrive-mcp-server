# BR-032 — Fresh decision evidence

## Rule

Every decision acquires fresh ancestry/path evidence without cross-decision caching, including consecutive checks of the same identity.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Prevent earlier successful reads from authorizing subsequently moved objects.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** file 13 freshly proved beneath root 10, **When** reading it, **Then** the first read is authorized.
- **Given** file 13 moved to /outside after that read, **When** reading it again, **Then** a second inspection occurs and ACCESS_DENIED is returned.

Both examples map to the test or parameter rows named below.
