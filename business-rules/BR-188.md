## Rule

`make image-binfmt`, when `IMAGE_PLATFORMS` contains `linux/arm64` and `uname -m` is neither `aarch64` nor `arm64`, runs `docker run --rm --privileged tonistiigi/binfmt@sha256:<64 hex> --install arm64`; otherwise it prints one skip line and exits 0. It is the only Make recipe with `--privileged`, and it is never a prerequisite of another target.

## Rationale

arm64 is emulated without third-party Actions, and the privileged step is never implicit. Source: [F-013 v1](../features/F-013-http-image.md).

## Examples

- **Given** an `x86_64` host and `IMAGE_PLATFORMS=linux/arm64`
  **When** `make image-binfmt` runs
  **Then** it runs the digest-pinned binfmt image with `--install arm64`
- **Given** an `aarch64` host
  **When** `make image-binfmt` runs
  **Then** it prints one skip line, calls no docker command and exits 0
