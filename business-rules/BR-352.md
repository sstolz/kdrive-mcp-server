# BR-352 — Privacy scan without dependencies

## Rule

`scripts/privacy-scan.ts` imports only Node built-ins (`node:` modules), so it needs no `node_modules`. `make privacy-scan` depends only on the container-config guard (not `_require-setup`) and runs exactly `$(COMPOSE) run --rm -T` with the `-e PRIVACY_*` names, then `dev node scripts/privacy-scan.ts`; the CI job does not run `make setup`. The existing dev-service mounts apply (`.git` read-only); no dedicated network-isolated service is added.

## Rationale

No third-party package runs in the job that holds the deny secret (D-9). Source: [F-023 v1](../features/F-023-hosted-ci-privacy-scan.md).
