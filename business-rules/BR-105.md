## Rule

The qualification command and its reports stay out of the npm package: no `scripts/` file and no report is packed, while the built `src/auth/` modules and the exact pinned `jose` dependency are.

## Rationale

The published package carries only the runtime validator, never a development tool or owner evidence. Source: [F-008 v1](../features/F-008-oidc-qualification.md), AC-17.

## Examples

- **Given** the packed artifact.
  **When** its file list is read.
  **Then** it contains `dist/auth/access-token.js` and no `scripts/` or `artifacts/` file.
- **Given** `package.json`.
  **When** its dependencies are read.
  **Then** `jose` is exactly `6.2.12`.
