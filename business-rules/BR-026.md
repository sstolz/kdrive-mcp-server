# BR-026 — Explicit guarded credential sources

Source: [F-002 v1](../features/history/F-002-v1.md), BR-026, frozen
2026-11-01 21:18:28 UTC after fresh independent approval.

## Rule

Load a required nonempty Infomaniak credential from the selected
environment value or explicit file reference. Permit the proxy upstream secret
from the selected environment value or explicit file reference, and its signing
material only by explicit file reference. Reject raw secrets in CLI/YAML,
conflicting selectors and invalid credential data under the file contract below.
Read nothing from unselected credential sources. No secret is generated,
copied to the repository, written to disk or passed as an argument.

The source specification's inventory, bounds, grammars, auth matrix, credential
contract, error mapping and preflight port supply the normative details for
this statement; this record does not redefine those tables.

## Rationale

Read only selected bounded credentials without raw CLI/YAML secrets or discovery.
