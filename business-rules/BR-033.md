# BR-033 — Complete consistent evidence

## Rule

Invalid, missing, contradictory, cyclic, failed or incomplete evidence produces a denial without protected dispatch.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Treat unknown or contradictory provider results as insufficient authority.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** a missing normalized inspection result, **When** reading file 13, **Then** ACCESS_DENIED is returned with zero execution.
- **Given** an inspection with path /r/b/report but parents /r/a, **When** reading file 13, **Then** ACCESS_DENIED is returned with zero execution.

Both examples map to the test or parameter rows named below.
