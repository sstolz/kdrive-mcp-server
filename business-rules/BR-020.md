# BR-020 — Complete explicit root coverage

Statement preserved from [F-002 v1](../features/history/F-002-v1.md); accepted under [F-002 v2](../features/F-002-configuration.md). The v2 CLI diagnostic phase ordering applies without rewriting this rule.

## Rule

Parse roots by the grammar below. Absent roots mean ID `1` on
each configured drive. Present roots must be nonempty, cover every configured
drive and mention no other drive. Preserve configured order, reject duplicate
selectors and never fill a missing drive in a present list with its whole root.
Resolving a path never changes the configured-drive allowlist.

The source specification's inventory, bounds, grammars, auth matrix, credential
contract, error mapping and preflight port supply the normative details for
this statement; this record does not redefine those tables.

## Rationale

A partial root list must never silently expose a configured drive in full.

## Examples

These examples illustrate the accepted rule; they do not replace the source specification or claim a new test execution. Unless a scenario overrides them, local-loader fixtures use explicit drive `7` and token `SYNTHETIC_TOKEN`, with no deployment state. Each verification reference identifies one existing test case or table row.

- **Given** valid synthetic configuration with only drive `7` and no roots setting.
  **When** roots are normalized.
  **Then** the selected root is exactly `{driveId: 7, kind: id, value: 1}`.
  Verified by: [`derives defaults while retaining exact allowlists`](../tests/config.test.ts), absent-roots assertion.

- **Given** drives `7,8` and explicit roots `8:/Folder,7:042`.
  **When** roots are normalized.
  **Then** selectors remain in supplied order: drive `8` path `/Folder`, then drive `7` ID `42`.
  Verified by: [`derives defaults while retaining exact allowlists`](../tests/config.test.ts), explicit multi-drive roots assertion.

- **Given** drive `7` and present-empty `KDRIVE_MCP_ROOTS=''`.
  **When** explicit roots are validated.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}`; the absent-roots default does not return.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), empty-roots row.

- **Given** drives `7,8` and explicit roots `7:1`.
  **When** root coverage is validated.
  **Then** it rejects with `{code: MISSING_REQUIRED, setting: roots}` and does not fill drive `8` with root ID `1`.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), missing-drive-8 row.

- **Given** drives `7,8` and explicit roots `9:1`.
  **When** root membership and coverage are validated.
  **Then** it rejects with `{code: DRIVE_NOT_ALLOWED, setting: roots}` before reporting missing coverage.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), unconfigured-drive-9 row.

- **Given** drive `7` and roots `7:1,07:01`.
  **When** selector duplicates are checked after numeric normalization.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}`.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), normalized duplicate row.

- **Given** explicit YAML `roots: ["7:/A, B/%20/é", "7:/"]`.
  **When** roots are parsed.
  **Then** paths remain exactly `/A, B/%20/é` and `/`; comma, percent, Unicode and the explicit whole root are preserved.
  Verified by: [`preserves literal YAML paths and allows explicit whole roots`](../tests/config.test.ts), literal YAML paths assertion.

- **Given** environment roots `7:/a,b`.
  **When** the comma-separated environment list is parsed.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}`; the comma cannot be escaped into a single environment path.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), path `/a,b` row.

- **Given** environment roots `7:/a/`.
  **When** root-path grammar is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}` because trailing slash is allowed only for `/`.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), path `/a/` row.

- **Given** environment roots `7:/a//b`.
  **When** root-path grammar is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}` for an empty path component.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), path `/a//b` row.

- **Given** environment roots `7:/a/../b`.
  **When** root-path grammar is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}` for a parent component.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), path `/a/../b` row.

- **Given** drive `7` and root path `/` followed by 2,047 `é` characters then `a`, exactly 4,096 UTF-8 path bytes.
  **When** root-path bounds are checked.
  **Then** the path is accepted without changing its Unicode content.
  Verified by: [`accepts exact string/list maxima and rejects adjacent values`](../tests/config.test.ts), 4,096-byte path assertion.

- **Given** drive `7` and root path `/` followed by 4,096 ASCII `x` characters, exactly 4,097 UTF-8 path bytes.
  **When** root-path bounds are checked.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: roots}`.
  Verified by: [`enforces bounded %s`](../tests/config.test.ts), row `KDRIVE_MCP_ROOTS`.

- **Given** drive `7` and 256 explicit roots `7:1,7:2,...,7:256`.
  **When** root-list bounds are checked.
  **Then** all 256 roots are accepted.
  Verified by: [`accepts exact string/list maxima and rejects adjacent values`](../tests/config.test.ts), 256-root assertion.

- **Given** those 256 explicit roots followed by `,7:999`.
  **When** root-list bounds are checked.
  **Then** it rejects with `{code: LIMIT_EXCEEDED, setting: roots}` for 257 entries.
  Verified by: [`accepts exact string/list maxima and rejects adjacent values`](../tests/config.test.ts), 257-root assertion.

- **Given** environment roots `7:relative`.
  **When** root-path grammar is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}` because paths must be absolute.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), path `relative` row.

- **Given** environment roots `7:/./b`.
  **When** root-path grammar is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}` for a dot component.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), path `/./b` row.

- **Given** environment roots containing `7:/a`, a newline, then `b`.
  **When** root-path grammar is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}` for a control character.
  Verified by: [`rejects root/drive case %j`](../tests/config.test.ts), path `/a\nb` row.

- **Given** environment roots containing `7:/a\b` with a literal backslash.
  **When** root-path grammar is checked.
  **Then** it rejects with `{code: INVALID_VALUE, setting: roots}` for a backslash.
