# BR-260 — Strict mutation tool arguments

## Rule

Each of the five tools accepts exactly the arguments of the F-017 Tool table (strict objects, IDs and `drive_id` positive safe integers, `name` a valid F-003 single path component with no leading or trailing whitespace (JavaScript `\s`)), and builds exactly the listed operation with `drive_id` defaulting to the configured default drive; any other argument set returns `INVALID_ARGUMENTS` with zero gate runs, zero records and zero upstream requests.

Since v2 (F-018): the `name` of `kdrive_create_folder` and `kdrive_rename` equals its Unicode NFC normalization (`name === name.normalize("NFC")`); otherwise the call returns `INVALID_ARGUMENTS` with zero gate runs, zero records and zero upstream requests.

Since v3 (F-018 v3): the `name` of `kdrive_create_folder` and `kdrive_rename` is a well-formed UTF-16 string (it contains no code unit U+D800–U+DFFF outside a valid high-then-low surrogate pair); otherwise the call returns `INVALID_ARGUMENTS` with zero gate runs, zero records and zero upstream requests.

## Rationale

A write tool must reach the gate only with one well-formed operation; malformed input never costs a record or a request. Source: [F-017 v1](../features/F-017-controlled-tree-mutations.md). v3: a lone surrogate passes the component and NFC checks and is sent as a `\uDXXX` JSON escape whose storage by kDrive is unmeasured; a rename is judged on `cancel_id` only, so a rewritten name could be reported `succeeded` at an unchecked path ([F-018 v3](../features/F-018-upload.md), D-18-14).

## Examples

- **Given** `kdrive_rename` with `{file_id: 3, name: "renamed"}` and default drive 7
  **When** the tool is called
  **Then** the gate run receives `{kind:"rename", target:{driveId:7, id:3}, name:"renamed"}`
- **Given** `kdrive_rename` with `{file_id: 3, name: " x"}`
  **When** the tool is called
  **Then** it returns `INVALID_ARGUMENTS` and no gate run starts
- **Given** `kdrive_rename` with `{file_id: 3, name: "a\uD800"}` (a lone high surrogate)
  **When** the tool is called
  **Then** it returns `INVALID_ARGUMENTS`, no gate run starts and no request is sent
- **Given** `kdrive_create_folder` with `{parent_id: 5, name: "\uDC00"}` (a lone low surrogate)
  **When** the tool is called
  **Then** it returns `INVALID_ARGUMENTS`, no gate run starts and no request is sent
- **Given** `kdrive_rename` with `{file_id: 3, name: "a\uD83D\uDE00b"}` (a valid surrogate pair, U+1F600) and default drive 7
  **When** the tool is called
  **Then** the gate run receives `{kind:"rename", target:{driveId:7, id:3}, name:"a\uD83D\uDE00b"}`
