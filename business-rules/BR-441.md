## Rule

The hidden reader consumes controls as follows: CR or LF completes the line, Ctrl-C rejects with `Interrupted`, DEL (`U+007F`) keeps its existing backspace edit, Ctrl-D (`U+0004`) rejects with `Input ended`, and any other Unicode `Cc` character, including backspace (`U+0008`) and ESC (`U+001B`), rejects with `Unsupported control character` rather than stripping or returning it.

## Rationale

Refusing residual controls prevents escape-sequence input without silently changing secrets.
Source: [F-052 v1](../features/F-052-oauth-qualification-proxy-hardening.md).

## Examples

- **Given** hidden input containing Ctrl-D
  **When** the reader reaches that control
  **Then** it rejects with `Input ended`. Maps to
  `BR-441 v1 AC-06 controls refuse without silent stripping`.
- **Given** hidden input containing backspace, TAB, NUL, C1 or ESC
  **When** the first such control arrives, including across chunks
  **Then** it rejects with `Unsupported control character` without returning or
  echoing input. Maps to the same AC-06 test.
- **Given** hidden input `abx`, DEL, `c`, then CR or LF
  **When** the reader settles
  **Then** it returns `abc`; Ctrl-C instead rejects with `Interrupted`.
  Maps to the same AC-06 test.
