# BR-261 — Mutation tool annotations

## Rule

Each of the five tools carries `readOnlyHint:false`, `idempotentHint:false`, `openWorldHint:true`, and `destructiveHint:true` for `kdrive_trash` only (`false` for the other four).

## Rationale

Clients must not replay a write automatically (D-17-7); only trash is destructive. Source: [F-017 v1](../features/F-017-controlled-tree-mutations.md).

## Examples

- **Given** mode `write`
  **When** tools are listed
  **Then** `kdrive_trash` has `destructiveHint:true`
- **Given** mode `write`
  **When** tools are listed
  **Then** `kdrive_rename` has `destructiveHint:false` and `idempotentHint:false`
