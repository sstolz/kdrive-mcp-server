# BR-416 — Content projection

## Rule

A selected page's content is its `Contents` stream, or the streams of a `Contents` array of at most 1,024 references joined with one line feed, tokenized once in order, with the page's `Resources` (own or inherited) as resource scope. Each stream is decoded and tokenized once per invocation (BR-414), but every use counts its decoded length against B: each reference of a selected page's `Contents` beyond the stream's first use, on the same page or another selected page, adds the stream's decoded length again, as the references are read and before the page's content is joined or tokenized, and the reference that passes the remaining B refuses as `LIMIT_EXCEEDED`; dropped operators, which emit no token, are thus paid for at every use. Kept, with the F-009 operand checks: `q`, `Q`, `cm`, `BT`, `ET`, the text state operators `Tf`, `Tc`, `Tw`, `Tz`, `TL`, `Ts` and `Tr` (integer 0–7), and inside `BT`/`ET` only `Td`, `TD`, `Tm`, `T*`, `Tj`, `TJ`, `'` and `"`. As in F-009 and ISO 32000-1 §8.2, `BT` inside a text object, `ET` outside one, `Td`, `TD`, `Tm`, `T*` or a text-show operator outside `BT`/`ET`, and `q`, `Q` or `cm` inside `BT`/`ET` refuse as `UNSUPPORTED_FORMAT` (PDF.js runs them with state rules of its own, which the preflight does not model). The F-009 limit of 32 nested `q` levels is counted on the canonical stream of the page, the `q` that wraps each inlined Form and the Forms' own `q`s included (BR-419); the `q` that opens a 33rd level refuses as `UNSUPPORTED_FORMAT`. String bytes are not restricted to 0x20–0xFF, and `Tf` takes a font name of the resource scope and a size that passes the F-009 numeric operand check, is not 0 and is at most 100,000 in absolute value (otherwise `UNSUPPORTED_FORMAT`); negative and fractional sizes are admitted. This measured bound replaces the F-009 size range 1–512: within it the size only changes the geometry of PDF.js's items, as it does on the source, while size 0 drops PDF.js's line ends and, at 250,000, a line of three words no longer fits the largest page the numeric check admits, so PDF.js leaves out its last glyphs (F-034 Measurement 3, D-13). Text state is part of the graphics state: it persists across `BT`/`ET`, is saved and restored by `q`/`Q`, `BT` resets only the text matrices, and text state operators are kept inside or outside `BT`/`ET`. A text-show operator with no font set refuses as `CONTENT_UNAVAILABLE`. Dropped, operands included: path construction and painting, clipping, colour and colour space, line and rendering state, `sh`, marked content (`BMC`, `BDC`, `EMC`, `MP`, `DP`), `BX`/`EX`, `gs` (refused when the ExtGState it names in the resource scope holds `/Font`), `Do` of an Image or PostScript XObject, and inline images whose data is framed as follows: after `BI`, at most 32 key/value pairs up to `ID`, with direct values only, and one white-space byte; the data length is `/L` (or `/Length`) when present, else, when the first filter of `/F` (or `/Filter`) is `/AHx` (or `/ASCIIHexDecode`), the bytes up to and including the first `>`, else, when it is `/A85` (or `/ASCII85Decode`), the bytes up to and including the first `~>`, else, with no filter, the computed size, else, when the only filter is `/Fl` (or `/FlateDecode`) with no `/DP` (or `/DecodeParms`), the input bytes that one inflate of BR-414 consumes (`maxOutputLength` the smaller of the computed size and the remaining B). The computed size is `H` × ceil(`W` × `BPC` × components / 8), where `W` and `H` are 1–65,536, `BPC` is 1, 2, 4, 8 or 16 and is 1 when absent with `/IM true`, and components are 1 for `/G`, `/I`, an indexed space or `/IM true`, 3 for `/RGB` and 4 for `/CMYK`, long names included; a `W` or `H` over 65,536 refuses as `LIMIT_EXCEEDED`. After the data come optional white space and `EI` followed by white space, a delimiter or the end. An inline image whose length is none of these refuses as `UNSUPPORTED_FORMAT`; framing that overruns the content or is not followed by `EI` refuses as `CONTENT_UNAVAILABLE`; an inflate whose output passes the remaining B refuses as `LIMIT_EXCEEDED`; one whose output passes the computed size first, a consistency check and not a ceiling, refuses as `CONTENT_UNAVAILABLE`, as does a zlib stream that does not end within the content; inflated inline bytes count against B. `Do` of a Form XObject is inlined by BR-419. `Do` inside `BT`/`ET`, `d0`, `d1` and any other operator refuse as `UNSUPPORTED_FORMAT`. A `Q` with no open `q` of the same content stream or Form is dropped, and `Q`s are appended for the `q`s left open at its end. The kept tokens are rebuilt by the canonical serializer (numbers in the F-009 form, strings as hexadecimal strings, names with `#xx` escapes for bytes outside 0x21–0x7E, delimiters and `#`, `Tf` operands renamed to the canonical font names), never copied as source bytes; that stream counts against the canonical bound.

## Rationale

Common content carries graphics, colour, marked content and inline images around text (F-034 S12, S13, S18, S19, S27–S29). Keeping only text operators, rebuilt canonically, admits it while PDF.js executes only checked tokens; inline image data is skipped by a length that never depends on a search for `EI` (F-034 D-10). Source: [F-034 v1](../features/F-034-pdf-extraction-profile.md).

## Examples

- **Given** text between `rg`, `re f` and `BDC`/`EMC` operators
  **When** page 1 is read
  **Then** its text, and the canonical content holds only kept operators
- **Given** a ReportLab inline image with `/F [/A85 /Fl]` before the text
  **When** page 1 is read
  **Then** its text
- **Given** an inline image with `/F /DCT` and no `/L`
  **When** page 1 is read
  **Then** `UNSUPPORTED_FORMAT` before PDF.js
- **Given** a `Contents` array of 1,024 references
  **When** page 1 is read
  **Then** its text
- **Given** a `Contents` array of 1,025 references
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js
- **Given** a Flate inline image with `W` and `H` 65,536, `BPC` 16 and `/CMYK` whose data inflates past the remaining B
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js, with no more than the remaining B inflated
- **Given** a Flate inline image whose data inflates to one byte more than its computed size
  **When** page 1 is read
  **Then** `CONTENT_UNAVAILABLE` before PDF.js
- **Given** an unfiltered image mask with `/IM true` and no `/BPC`, framed by size
  **When** page 1 is read
  **Then** its text
- **Given** an unfiltered `/G` inline image with `BPC` 1, `H` 1 and `W` 65,537
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js
- **Given** a stream of L bytes of dropped operators referenced 1,024 times by the `Contents` of each of 10 selected pages, using exactly B decoded bytes with the rest of the file
  **When** the 10 pages are read
  **Then** their text
- **Given** the same file using B + 1 decoded bytes
  **When** the 10 pages are read
  **Then** `LIMIT_EXCEEDED` at a `Contents` array, before that page's content is tokenized
- **Given** `q` inside `BT`/`ET`
  **When** page 1 is read
  **Then** `UNSUPPORTED_FORMAT` before PDF.js, as in F-009
- **Given** a `Tf` size of 0.5
  **When** page 1 is read
  **Then** its text
- **Given** a `Tf` size of 0, or of 100,001
  **When** page 1 is read
  **Then** `UNSUPPORTED_FORMAT` before PDF.js
