# BR-401 — Style hash in the CSP

## Rule

The `Content-Security-Policy` of every proxy HTML page is `default-src 'none'; frame-ancestors 'none'; base-uri 'none'; style-src 'sha256-<b64>'`, where `<b64>` is the base64 SHA-256 of the exact UTF-8 text between `<style>` and `</style>`, computed once from the same constant that is rendered. No `'unsafe-inline'`, nonce or other source is added; the other BR-129 headers are unchanged.

## Rationale

The BR-129 policy forbade inline styles; whitelisting the one static stylesheet by hash keeps every other style and every script blocked (F-030 D-1). Source: [F-030 v1](../features/F-030-oauth-proxy-page-design.md).

## Examples

- **Given** any proxy HTML page
  **When** its headers are read
  **Then** the CSP ends with `style-src 'sha256-<b64>'` where `<b64>` is the hash of its `<style>` text, identical on every page
- **Given** any proxy HTML page
  **When** its CSP is read
  **Then** it holds no `'unsafe-inline'` and no nonce
