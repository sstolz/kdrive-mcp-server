# BR-321 — Dependency audit documentation

## Rule

v3 (F-025 v1, #2, pending acceptance; v1 below stays the active rule until then): `docs/development.md` no longer states that the audit is not clean; its dependency-audit paragraph names the BR-315 overrides, ADR-009, `make audit` and the CI `audit` job. `SECURITY.md` has a section `## Dependency audit` stating that CI fails on any high or critical `npm audit` finding, that a new one is fixed before a release, not allowlisted, and that the overrides do not apply to an install of the packed tarball (`npm install -g`), which can resolve Jimp's nested Zod 3 again. `CHANGELOG.md` has a `### Fixed` line for the advisories and an `### Added` line for `make audit` and the CI job, both citing #104, located as follows. A release section is a level-2 section whose heading has the form `## [<version>] - <YYYY-MM-DD>`; a heading without the date is not one. A line cites #104 when it matches `#104\b` (`#1040` does not cite #104). If any release section exists, a release section citing #104 must exist, and the first such section in file order has both lines; otherwise `## [Unreleased]` has both.

v2 (F-024 v1): proposed, withdrawn in F-024 v2, never accepted; the number is not reused.

v1 (F-020 v1, accepted): `docs/development.md` no longer states that the audit is not clean; its dependency-audit paragraph names the BR-315 overrides, ADR-009, `make audit` and the CI `audit` job. `SECURITY.md` has a section `## Dependency audit` stating that CI fails on any high or critical `npm audit` finding, that a new one is fixed before a release, not allowlisted, and that the overrides do not apply to an install of the packed tarball (`npm install -g`), which can resolve Jimp's nested Zod 3 again. `CHANGELOG.md` Unreleased has a `### Fixed` line for the advisories and an `### Added` line for `make audit` and the CI job, both citing #104.

## Rationale

Operators and contributors must know the audit contract and the residual tarball-install risk (D-1). Source: [F-020 v1](../features/F-020-dependency-audit.md).
