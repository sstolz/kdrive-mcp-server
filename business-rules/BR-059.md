## Rule

Runtime construction requires the exact successful preflight object, of transport `stdio` or `http`, and explicit trusted dependencies and performs no provider or process I/O until started; the stdio runner refuses a configuration whose transport is not `stdio` before it uses a stream or a dependency.

## Rationale

Construction needs a proved configuration rather than a caller-shaped object. Source: [F-005 v1](../features/history/F-005-v1.md), AC-01; version 2 is [F-005 v2](../features/F-005-stdio-navigation.md), frozen with [F-012 v1](../features/F-012-authenticated-http.md) (each HTTP session builds its own server with the same tools and policy).

## Examples

- **Given** a successful F-002 stdio preflight object and explicit synthetic ports.
  **When** the runtime factory is constructed.
  **Then** no port is called and a server is returned.
- **Given** a copied configuration.
  **When** the factory is constructed.
  **Then** construction throws without port calls.
- **Given** a successful F-002 HTTP preflight object (`--http --insecure-no-auth`) and explicit synthetic ports.
  **When** the factory is constructed.
  **Then** no port is called and a server is returned.
- **Given** the same HTTP preflight object and injected streams.
  **When** the stdio runner starts.
  **Then** it throws the fixed `TypeError`, no port is called and nothing is written to the output stream.
