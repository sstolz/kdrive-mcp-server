## Rule

`make kdrive-record` and `make kdrive-acceptance` refuse, before any Docker command, a `KDRIVE_ACCEPTANCE_DIR` that is not an absolute directory outside the checkout, is a symlink, is unreadable, or holds entries other than `kdrive-token` and `fixtures.json`; they mount it read-only at `/run/kdrive-acceptance` and pass the token only as `KDRIVE_TOKEN_FILE=/run/kdrive-acceptance/kdrive-token`.

## Rationale

The token and private manifest must come from an owner directory outside the checkout, mounted read-only, never from the repository. Source: [F-014 v1](../features/F-014-production-kdrive-adapter.md).

## Examples

- **Given** `KDRIVE_ACCEPTANCE_DIR` set to a relative path
  **When** `make kdrive-record` runs
  **Then** it prints `Set KDRIVE_ACCEPTANCE_DIR to an absolute directory outside the checkout.` and no Docker command runs.
- **Given** a valid external directory
  **When** `make kdrive-record` runs
  **Then** it is mounted read-only at `/run/kdrive-acceptance` with only `KDRIVE_TOKEN_FILE` passed.
