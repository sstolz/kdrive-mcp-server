# BR-013 — Private trusted-main remote analysis

## Rule

opt-in official scanner Docker analyzes only a clean exact trusted
main snapshot against `https://sonar.example.org`, after verifying an
existing private project/key, installed compatibility and runtime token. No
project creation, settings change, PR/branch upload or local server. Mount
source/fresh LCOV read-only, with distinct writable non-root work/cache volumes.
Token reaches scanner only, never dev/tests, arguments, echoes/logs or files.
Use relative LCOV property, wait for this task's gate for 300 seconds, enforce a
15-minute overall deadline and fail on any processing/gate/network/timeout error.
Quality runs check then analysis; check requires no remote configuration.

## Rationale

preserve source privacy and prevent stale/untrusted analysis results.
