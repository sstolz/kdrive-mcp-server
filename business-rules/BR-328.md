# BR-328 — Quality Gate summary only on a failed scan

## Rule

The summary runs only when the scanner exits nonzero and the analysis deadline has not expired; when the scanner exits 0, no summary line is printed and no request beyond the scanner's own is made.

## Rationale

Keeps green logs and API traffic unchanged (D-3). Source: [F-022 v1](../features/F-022-sonar-gate-summary.md).

## Examples

- **Given** a fake scanner exiting 0 with valid task metadata
  **When** `runAnalysis` runs
  **Then** it returns 0, the fake `fetch` records zero calls and no `Quality Gate summary` line prints
- **Given** a fake scanner exiting 2 with valid task metadata and a `PENDING` task
  **When** `runAnalysis` runs
  **Then** it returns 2 and prints `Quality Gate summary unavailable: task stage failed.`

## Verification

tests/sonar-summary.test.ts: `BR-328 no summary on a passing gate`, `BR-328 summary on nonzero exit`. Run with Docker/Make `make check`; no Sonar server, network or secret is used.
