## Rule

Mode `read` registers exactly the ten read tools; modes `write` and `share` register exactly those ten plus the five F-017 tools and `kdrive_upload`; every mode registers the single existing complete-binary resource template and no prompt or enumerated resource.

## Rationale

Clients discover only the cumulative read surfaces actually implemented by the injected composition. Source: [F-009 v1](../features/F-009-bounded-content-reading.md).

## Examples

- **Given** read mode.
  **When** the SDK lists tools, resource templates and concrete resources.
  **Then** ten annotated read tools, one complete-binary template and zero concrete resources appear.
- **Given** write or share mode.
  **When** the same discovery requests run.
  **Then** fifteen tools appear (the ten read tools, then the five mutation tools), with the same template and no prompt.
