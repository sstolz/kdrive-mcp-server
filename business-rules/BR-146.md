# BR-146 — The Sonar host is never printed

## Rule

v2 (F-022 v1, #114; accepted on main `e7d6367`, 2026-11-12): v1 holds unchanged, and in addition every line the Quality Gate summary of `scripts/sonar.ts` prints passes through `redact(text, token, hostname)`, and its fixed messages never contain the host, the host file content, the token or a response body.

v1: The host is never printed: the wrapper replaces every ASCII case-insensitive
occurrence of the configured host name in captured scanner stdout/stderr with
`[REDACTED]` (including occurrences split across chunks or streams, as for the
token), and no message from `scripts/sonar-entry.sh`, `scripts/sonar-snapshot.ts`
or `scripts/sonar.ts` includes the host value, the host file path content or the
token.

## Rationale

The host is confidential by owner decision; GitHub masking is exact-case and absent locally, so the wrapper redacts it itself. Source: [F-011 v1](../features/F-011-pre-merge-quality-gates.md); v2: [F-022 v1](../features/F-022-sonar-gate-summary.md), whose summary prints server-supplied text (T2).

## Examples

- **E-01 — Given** a fake scanner printing `sonar.example.test` whole, upper-cased and split across chunks and streams
  **When** the wrapper captures its output
  **Then** the log shows only `[REDACTED]` for each occurrence.
- **E-02 — Given** a scanner error naming `SONAR.example.TEST`
  **When** the wrapper reports the failure
  **Then** the message omits the host.
- **E-03 (v2) — Given** a Quality Gate summary whose condition and issue fields name `Sonar.EXAMPLE.test` and the token
  **When** the summary prints them
  **Then** each occurrence reads `[REDACTED]`.
- **E-04 (v2) — Given** a task request answering HTTP 500 with a body naming the host and the token
  **When** the summary prints the stage line
  **Then** the line is `Quality Gate summary unavailable: task stage failed (HTTP 500).`, with no body, URL, host or token.
