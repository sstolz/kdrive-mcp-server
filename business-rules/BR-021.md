# BR-021 — Fail-closed injected drive and root preflight

Statement preserved from [F-002 v1](../features/history/F-002-v1.md); accepted under [F-002 v2](../features/F-002-configuration.md). The v2 CLI diagnostic phase ordering applies without rewriting this rule.

## Rule

Asynchronous preflight accepts only a locally prepared
configuration and an explicitly injected resolver. It checks every configured
drive before resolving any root, permits only exact role `admin`, and rejects
missing, mismatched, `external` or unknown-role results. It then validates every
selected folder ID and resolves every selected path to exactly one existing
directory in the same drive. For a numeric selector, the returned normalized
folder ID must equal the selected folder ID exactly; another existing
directory, including ID `1`, cannot substitute. Absent, ambiguous, wrong-ID,
wrong-drive, non-directory,
malformed or rejected results fail the entire preflight. No partially resolved
configuration escapes. Return only configured drives and their resolved IDs;
duplicate resolved `(driveId, folderId)` pairs collapse in first-selector order.
Bind each successful root to its ID, with no subsequent path rebinding in this
feature. An absent resolver fails with `PREFLIGHT_UNAVAILABLE`; it never returns
a remotely ready configuration. No root is authorized by syntax alone.

The source specification's inventory, bounds, grammars, auth matrix, credential
contract, error mapping and preflight port supply the normative details for
this statement; this record does not redefine those tables.

## Rationale

A root must resolve to the intended directory without external-drive exposure or partial success.

## Examples

These examples illustrate the accepted rule; they do not replace the source specification or claim a new test execution. Unless a scenario overrides them, local-loader fixtures use explicit drive `7` and token `SYNTHETIC_TOKEN`, with no deployment state. Each verification reference identifies one existing test case or table row.

- **Given** local drives `[7, 8]`, selectors `7:42,8:/Folder,7:/Alias`, injected `admin` results for both drives, and same-drive directory ID `42` for every selector.
  **When** preflight runs.
  **Then** the call order is `drive:7`, `drive:8`, `root:7:42`, `root:8:/Folder`, `root:7:/Alias`; resolved roots are exactly `[{driveId:7, folderId:42}, {driveId:8, folderId:42}]`, with the alias collapsed and no unconfigured drive added.
  Verified by: [`BR-021 BR-028 inspects only configured drives before roots and collapses resolved aliases`](../tests/config-preflight.test.ts).

- **Given** local drives `[7, 8]` and injected first-drive result `{id:7, role:external}`.
  **When** preflight checks the first drive.
  **Then** it rejects with `{code: DRIVE_NOT_ALLOWED, setting: driveIds}` without any root-resolution call.
  Verified by: [`BR-021 rejects untrusted drive result %j before roots`](../tests/config-preflight.test.ts), row `{id:7, role:"external"}`.

- **Given** local drives `[7, 8]` and injected first-drive result `{id:7, role:owner}`.
  **When** preflight checks the first drive.
  **Then** it rejects with `{code: DRIVE_NOT_ALLOWED, setting: driveIds}`; an unknown role does not substitute for exact `admin`.
  Verified by: [`BR-021 rejects untrusted drive result %j before roots`](../tests/config-preflight.test.ts), row `{id:7, role:"owner"}`.

- **Given** local first drive `7` and injected first-drive result `{id:8, role:admin}`.
  **When** preflight validates the drive identity.
  **Then** it rejects with `{code: DRIVE_NOT_ALLOWED, setting: driveIds}` without resolving roots.
  Verified by: [`BR-021 rejects untrusted drive result %j before roots`](../tests/config-preflight.test.ts), row `{id:8, role:"admin"}`.

- **Given** local first root ID `42`, valid admin drive results and injected root result `{driveId:7, id:1, type:dir}`.
  **When** preflight resolves the first selector.
  **Then** it rejects with `{code: ROOT_NOT_RESOLVED, setting: roots}` after one resolution, returns no partial configuration and calls no later selector.
  Verified by: [`BR-021 BR-027 rejects invalid directory %j with no later selector`](../tests/config-preflight.test.ts), row `{driveId:7,id:1,type:"dir"}`.

- **Given** local first root ID `42`, valid admin drive results and injected root result `{driveId:7, id:43, type:dir}`.
  **When** preflight resolves the first selector.
  **Then** it rejects with `{code: ROOT_NOT_RESOLVED, setting: roots}` after one resolution; another existing directory cannot substitute.
  Verified by: [`BR-021 BR-027 rejects invalid directory %j with no later selector`](../tests/config-preflight.test.ts), row `{driveId:7,id:43,type:"dir"}`.

- **Given** local first root ID `42`, valid admin drive results and injected root result `{driveId:8, id:42, type:dir}`.
  **When** preflight validates the resolved drive.
  **Then** it rejects with `{code: ROOT_NOT_RESOLVED, setting: roots}` after one resolution.
  Verified by: [`BR-021 BR-027 rejects invalid directory %j with no later selector`](../tests/config-preflight.test.ts), wrong-drive row.

- **Given** local first root ID `42`, valid admin drive results and injected root result `{driveId:7, id:42, type:file}`.
  **When** preflight validates the resolved type.
  **Then** it rejects with `{code: ROOT_NOT_RESOLVED, setting: roots}` after one resolution.
  Verified by: [`BR-021 BR-027 rejects invalid directory %j with no later selector`](../tests/config-preflight.test.ts), file row.

- **Given** local first root ID `42`, valid admin drive results and injected `{ambiguous:true}`.
  **When** preflight resolves the first selector.
  **Then** it rejects with `{code: ROOT_NOT_RESOLVED, setting: roots}` after one resolution, without a partial result.
  Verified by: [`BR-021 BR-027 rejects invalid directory %j with no later selector`](../tests/config-preflight.test.ts), ambiguous row.

- **Given** local first root ID `42`, injected drive IDs `07` and `08` with exact role `admin`, and same-drive directory ID string `042`.
  **When** preflight normalizes returned IDs.
  **Then** the first resolved root is `{driveId:7, folderId:42}`; normalized equality satisfies the numeric selector.
  Verified by: [`BR-021 accepts canonical numeric string IDs without widening selectors`](../tests/config-preflight.test.ts).

- **Given** locally prepared configuration and no injected resolver.
  **When** preflight is requested.
  **Then** it rejects with `{code: PREFLIGHT_UNAVAILABLE, setting: preflight}`.
  Verified by: [`BR-027 BR-028 rejects absent resolver and sanitizes unexpected callback errors`](../tests/config-preflight.test.ts), absent-resolver assertion.

- **Given** locally prepared configuration and injected drive inspection that throws `Error("CANARY")`.
  **When** preflight inspects a drive.
  **Then** it rejects with `{code: PREFLIGHT_FAILED, setting: preflight}` without returning a partial configuration.
  Verified by: [`BR-027 BR-028 rejects absent resolver and sanitizes unexpected callback errors`](../tests/config-preflight.test.ts), phase `drive`.

- **Given** local first root ID `42`, valid admin drive results and injected root result `{driveId:7, id:0, type:dir}`.
  **When** preflight validates the returned ID.
  **Then** it rejects with `{code: ROOT_NOT_RESOLVED, setting: roots}` after one resolution because zero is outside the positive ID range.
  Verified by: [`BR-021 BR-027 rejects invalid directory %j with no later selector`](../tests/config-preflight.test.ts), zero-ID row.

- **Given** local first root ID `42`, valid admin drive results and injected root result `{driveId:7, id:42.5, type:dir}`.
  **When** preflight validates the returned ID.
  **Then** it rejects with `{code: ROOT_NOT_RESOLVED, setting: roots}` after one resolution because a fraction is not an integer ID.
  Verified by: [`BR-021 BR-027 rejects invalid directory %j with no later selector`](../tests/config-preflight.test.ts), fractional-ID row.
