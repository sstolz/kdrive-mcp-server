## Rule

The request given to the SDK transport carries no `Authorization` or `Cookie` header, and `handleRequest` receives no `authInfo`. No tool handler, `PolicyDependencies` call, `McpServer` or the F-010 upstream port receives a client bearer token; MCP requests make no upstream call.

## Rationale

A client bearer token has no consumer past verification; withholding it removes a leak surface and token passthrough. Source: [F-012 v1](../features/F-012-authenticated-http.md), AC-16.

## Examples

- **Given** a request with `Authorization` and `Cookie` headers
  **When** it reaches the SDK transport
  **Then** the transport request has neither header and no `authInfo`.
