# BR-009 — Docker-only Make development

## Rule

existing GNU Make 3.81/4.x orchestrates Docker Compose with no host
development toolchain. Help contacts no daemon/network. Setup builds official
digest-pinned Node 26.13.0 Bookworm dev, provides container Git, safely initializes
fresh dependency/cache volume identity and runs locked `npm ci`. Commands run
non-root with UID/GID mapping; never recursively chown the checkout. Check runs
ordered gates and fails fast, including parallel Make. Bind checkout at
`/workspace`, keep modules/npm cache in named volumes, persist outputs/lockfile.
No secrets, host credentials, ports, privileged mode or Docker socket. Exclude
private/output data from build context. No automatic cleanup or volume deletion.

## Rationale

reproducible development without modifying host tooling or data.
