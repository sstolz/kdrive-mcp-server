# BR-364 — Read-only checks that all run

## Rule

The release checks only read: Git commands that write no ref or object, and HTTP `GET` or `HEAD` requests plus the GHCR token request. Every check after input validation runs even when another fails.

## Rationale

A check run can never change the repository or a registry, and the owner sees every problem in one run. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** registry doubles that record methods
  **When** `release-check` runs
  **Then** they saw only `GET` and `HEAD`
- **Given** a failing commit check
  **When** `release-check` runs
  **Then** the CI, registry and environment checks still run and print a line
