## Rule

v3 (F-021 v1, #105; accepted on main `e208996`, 2026-11-11): v2 holds with these changes: the required sections add `Health check`; Current status states "The runtime image has a `HEALTHCHECK`" and no longer contains "It has no `HEALTHCHECK`"; the Health check section states what is checked (`/healthz`, `node /app/dist/healthcheck.js`, `127.0.0.1`, `MCP_HTTP_PORT`, `liveness`), `--no-healthcheck`, `Traefik` and `healthy`, the cases that need a `healthcheck.test` override (including `--port`), troubleshooting (`docker inspect`, `.State.Health`, `healthcheck failed:`) and orchestrator probes (`httpHeaders`, `invalid_host`, `timeoutSeconds`, `GET`); the `### 7. Verify` subsection contains `docker compose ps` and `healthy`. The full phrase list is in F-021 v1 BR-187 v3.

`docs/deployment.md` has sections Build, Startup, Secrets, Shutdown, Current status, "Personal server, step by step" and Troubleshooting. A section is the text after a line that is exactly `## <title>` (case-sensitive) up to the next line starting with `## `; phrases are case-sensitive substrings of its whitespace-collapsed text. The whole doc does not contain the v1 sentence ("The runtime image does not serve kDrive yet: ...", whitespace-collapsed, case-insensitive). Current status does not contain "not implemented" (case-insensitive) and states "The runtime image serves kDrive", "nothing is published to a registry" and "It has no `HEALTHCHECK`". Startup states that `0.0.0.0` is the container-internal bind address, that no host port is published and that `compose.yaml` and `config.yaml` (with `--config /config/config.yaml`) are alternatives. Shutdown states that SIGTERM triggers the F-012 BR-169 ordered close and that the grace period must be at least 10 s. Secrets states that secret files must be readable by UID 1000 and are never passed as environment values or build arguments. No file under `examples/` or `docs/deployment.md` contains, case-insensitively, `production-ready`, `production ready`, `ready for production` or `fully working`.

Version 1 (superseded by v2 on acceptance, 2026-11-11) required Current status to state verbatim: "The runtime image does not serve kDrive yet: until the HTTP runtime and the kDrive adapter land (#6, #7), the container reports that the runtime is not implemented and exits 1." and listed only the sections Build, Startup, Secrets, Shutdown and Current status.

## Rationale

Operators read an honest status before relying on the image. Source: [F-013 v1](../features/F-013-http-image.md). v2: the v1 sentence became false when F-014 made the image serve kDrive ([F-013 v3](../features/F-013-http-image.md), #101).
