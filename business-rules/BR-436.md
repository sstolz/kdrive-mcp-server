## Rule

Info `size_bytes` equals raw `size` only for files with a numeric non-negative safe integer in 0..9007199254740991; negative zero becomes zero. Every other value and every directory, including root 1, produces null.

## Rationale

Expose byte counts without coercion, fabricated zeroes, content reads or folder aggregation.

## Examples

- **Given** authorized file size -1
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR436_v1_size_boundaries`.
- **Given** authorized file size 0 or negative zero
  **When** info inspects the live item
  **Then** the scalar is `0`. Maps to `TestBR436_v1_size_boundaries`.
- **Given** authorized file size 1
  **When** info inspects the live item
  **Then** the scalar is `1`. Maps to `TestBR436_v1_size_boundaries`.
- **Given** authorized file size 9007199254740991
  **When** info inspects the live item
  **Then** the scalar is `9007199254740991`. Maps to `TestBR436_v1_size_boundaries`.
- **Given** authorized file size 9007199254740992
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR436_v1_size_boundaries`.
- **Given** authorized file size 0.5, NaN, infinity, missing, null, string, boolean, array or object
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR436_v1_size_boundaries`.
- **Given** authorized folder or root 1 size 16
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR436_v1_size_boundaries`.
