# BR-332 — Bounded summary responses and fixed stage lines

## Rule

A response body is read as a stream with a byte counter and the read is cancelled as soon as the count exceeds 1 MiB; `Content-Length` is never trusted and `res.text()`/`res.json()` are never used on the raw response. Each request's abort controller is aborted when its stage ends, whatever the outcome, so no unread body keeps a socket open. A stage fails on a network error, abort or per-request timeout, a redirect, a non-2xx status, a body over 1 MiB, invalid JSON, or a missing or mistyped required field. Required fields: `task` stage — `task.status` (string) and, when it is `SUCCESS`, a non-empty string `task.analysisId`; `conditions` stage — `projectStatus.status` (string) and `projectStatus.conditions` (array whose items have string `status` and `metricKey`); `issues` stage — `issues` (array whose items have string `rule`, `component` and `message`). A failed stage prints exactly one fixed line `Quality Gate summary unavailable: <stage> stage failed.` or, when the response status is non-2xx, `Quality Gate summary unavailable: <stage> stage failed (HTTP <status>).`, with `<stage>` in `task`, `conditions`, `issues`; a missing or mistyped required field prints `Quality Gate summary unavailable: <stage> stage failed (unexpected response).`; a `task.status` other than `SUCCESS` (for example `PENDING`) prints the plain `task stage failed.` line, and a `SUCCESS` without a non-empty `analysisId` prints the `(unexpected response)` line. A 2xx response with an oversized body or invalid JSON prints the plain line. No such line contains a response body, URL, host or token. Exactly one line is printed per failed stage.

## Rationale

Bounds memory and time and keeps response bodies, URLs, host and token out of the log (T2, T4, D-8, D-11). Source: [F-022 v1](../features/F-022-sonar-gate-summary.md).

## Examples

- **Given** a task answering HTTP 500 with a body naming the host and the token
  **When** the summary runs
  **Then** it prints only `Quality Gate summary unavailable: task stage failed (HTTP 500).`
- **Given** a task body streamed past 1 MiB with `Content-Length: 10`
  **When** the summary reads it
  **Then** the stream is cancelled after at most 1 MiB plus one chunk and `Quality Gate summary unavailable: task stage failed.` prints
