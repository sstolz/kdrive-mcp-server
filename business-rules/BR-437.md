## Rule

Info `modified_at` converts only numeric whole Unix seconds from `last_modified_at` in 0..253402300799 to UTC YYYY-MM-DDTHH:mm:ssZ for files and directories. All other optional values produce null, without fallback or unit guessing.

## Rationale

Publish portable timestamps while keeping unsupported metadata unknown and preserving required authorization evidence.

## Examples

- **Given** authorized file, folder or root timestamp -1
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR437_v1_timestamp_boundaries`.
- **Given** authorized file, folder or root timestamp 0 or negative zero
  **When** info inspects the live item
  **Then** the scalar is `1970-01-01T00:00:00Z`. Maps to `TestBR437_v1_timestamp_boundaries`.
- **Given** authorized file, folder or root timestamp 1
  **When** info inspects the live item
  **Then** the scalar is `1970-01-01T00:00:01Z`. Maps to `TestBR437_v1_timestamp_boundaries`.
- **Given** authorized file, folder or root timestamp 253402300799
  **When** info inspects the live item
  **Then** the scalar is `9999-12-31T23:59:59Z`. Maps to `TestBR437_v1_timestamp_boundaries`.
- **Given** authorized file, folder or root timestamp 253402300800
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR437_v1_timestamp_boundaries`.
- **Given** authorized timestamp 0.5, unsafe integer, NaN, infinity, missing, null, string, boolean, array or object
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR437_v1_timestamp_boundaries`.
- **Given** authorized missing last_modified_at with updated_at 1
  **When** info inspects the live item
  **Then** the scalar is `null`. Maps to `TestBR437_v1_timestamp_boundaries`.
