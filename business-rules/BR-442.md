## Rule

Every hidden-read exit once raw-mode activation is attempted attempts each cleanup step once, independently and best-effort: restore the pre-read raw state (`isRaw`, default false when unavailable), pause input, remove each of the read's data/end/error listeners and write one cleanup newline before settlement. This includes success, Ctrl-C, EOF, input error, control refusal and setup failure. A throwing cleanup step cannot prevent the remaining steps or settlement: preserve the specified payload-free read failure, or reject with exactly `Input failed` if cleanup fails on an otherwise successful read, without exposing the cleanup error payload or stack. If `setRawMode(true)` itself throws after the prompt, the same cleanup attempts restoration of the captured state. Setup failures during or after `setRawMode(true)` reject with exactly `Input failed`, without the original error text or stack, including when cleanup also fails. Admission first refuses non-TTY input or a missing raw-mode setter with `A terminal is required`, then refuses already-ended or destroyed input with `Input ended`; both checks precede the prompt, produce no prompt and no newline, and neither activates raw mode nor attaches read listeners. An exported `createProductionDeps` factory in `scripts/oidc-qualify.ts` takes the input and output streams, installs one payload-free stdin `error` handler before any read and returns the production dependencies including both hidden readers bound to those streams. The main block calls this factory once. The handler remains for the process lifetime, including between reads and after settlement; it exposes neither error payload nor stack. Late events cannot settle or clean up a read again.

## Rationale

Independent cleanup and a lifetime error sink prevent abandoned terminal state and uncaught late input errors.
Source: [F-052 v1](../features/F-052-oauth-qualification-proxy-hardening.md).

## Examples

- **Given** a raw or nonraw terminal
  **When** a read succeeds, fails or throws during raw-mode setup
  **Then** it attempts restoration of that initial state, pause, removal of all
  three owned listeners and one newline exactly once before settlement.
  Maps to `BR-442 v1 AC-07 every exit restores terminal state including Ctrl-C`.
- **Given** a cleanup step throws
  **When** a read exits
  **Then** all remaining steps are attempted, preserving a specified failure
  or rejecting success with `Input failed`. Maps to the same AC-07 test.
- **Given** ended or destroyed TTY input
  **When** a read starts
  **Then** it rejects with `Input ended` without output or setup; non-TTY or
  missing raw-mode setter takes precedence with `A terminal is required`.
  Maps to the same AC-07 test's admission case.
- **Given** dependencies from `createProductionDeps(input, output)`
  **When** payload-bearing errors arrive between sequential reads or after settlement
  **Then** one lifetime handler absorbs them without output or a second settlement.
  Maps to `BR-442 v1 AC-07 runner retains payload-free stdin error handler`.
