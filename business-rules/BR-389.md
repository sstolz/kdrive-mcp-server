# BR-389 — Image dependencies without Jimp

## Rule

`package.json` has no key starting with `@jimp/` in `dependencies`, `devDependencies` or `overrides`; `dependencies.pngjs` is exactly `7.0.0` and `dependencies["jpeg-js"]` exactly `0.4.4`. `package-lock.json` has no `packages` key containing `node_modules/@jimp/`, and has `node_modules/pngjs` at `7.0.0` and `node_modules/jpeg-js` at `0.4.4`. No `.ts` file under `src/`, `tests/` or `scripts/` imports a module specifier starting with `@jimp/`.

## Rationale

Every Jimp package carried a `zod ^3.23.8` range that npm `overrides` cannot move in an install of the packed tarball or the published package; removing Jimp removes that Zod 3 from every install, and exact pins keep the codecs Jimp already ran (D-1, D-5, ADR-010). Source: [F-027 v1](../features/F-027-direct-image-codecs.md).
