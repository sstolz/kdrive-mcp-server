## Rule

Collection output contains only the five declared metadata fields in every mode and never serializes raw or nested sharing metadata.

## Rationale

Provider sharing metadata is not part of the declared scalar listing contract. Source: [F-006 v1](../features/F-006-filtered-pagination.md).

## Examples

- **Given** nested users/teams/sharelink canaries.
  **When** a read/write/share collection runs.
  **Then** only the five declared scalar item fields appear.
- **Given** a dependency item has an accessor.
  **When** a collection runs.
  **Then** the accessor is never called or serialized.
