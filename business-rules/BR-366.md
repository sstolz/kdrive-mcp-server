# BR-366 — Release script internal error

## Rule

Any unexpected error in a `scripts/release.ts` mode is caught by one top-level handler that prints only `release: internal error` to stderr and exits 2; Git child processes run with stderr piped and discarded.

## Rationale

An unexpected failure must stop the release without printing a stack, a path or a server text. Source: [F-024 v2](../features/F-024-gated-publication.md).

## Examples

- **Given** a Git failure forced by the test
  **When** a mode runs
  **Then** stderr is exactly `release: internal error` and the exit is 2
