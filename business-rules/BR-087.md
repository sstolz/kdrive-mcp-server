## Rule

Unsupported resource representations refuse explicitly before any protected dependency call.

## Rationale

Unsupported rendering/offset shortcuts cannot bypass canonical targeting or output safety. Source: [F-007 v1](../features/F-007-bounded-downloads.md).

## Examples

- **Given** URI kdrive://7/file/3 is canonical.
  **When** a permitted fitting binary resource is read.
  **Then** one complete raw blob is returned.
- **Given** the URI adds ?representation=text or the SDK params add offset_bytes.
  **When** resources/read runs.
  **Then** UNSUPPORTED_REPRESENTATION returns with zero protected calls.
