# BR-417 — Font admission

## Rule

Only fonts selected by a kept `Tf` are read, at most 128 distinct fonts per invocation; a `Tf` naming no font of its resource scope refuses as `CONTENT_UNAVAILABLE`. Every key the projection keeps or reads is type-checked, and a wrong type or a missing required key refuses as `CONTENT_UNAVAILABLE`. Admitted: (a) `Type1`, `MMType1` or `TrueType` simple fonts whose encoding BR-420 resolves; (b) `Type0` with `/Encoding` the name `Identity-H` or `Identity-V`, one `CIDFontType0` or `CIDFontType2` descendant with a `FontDescriptor`, and a `ToUnicode` stream that maps every code the font's kept strings show (a shown code it does not map refuses as `UNSUPPORTED_FORMAT`; a string of odd length shown with it refuses as `CONTENT_UNAVAILABLE`); (c) `Type3` fonts whose encoding BR-420 resolves, projected as a simple font without a program: `FontMatrix` is an array of six numbers that pass the F-009 numeric operand check, the first above 0, the second and third 0 and the fourth not 0 (any other refuses as `UNSUPPORTED_FORMAT`), `FirstChar`, `LastChar`, `Widths` and `Encoding` are required, and `CharProcs`, `Resources`, `FontBBox` and `FontDescriptor` are never resolved or read. A `ToUnicode` given as a name, such as `/Identity-H`, refuses as `UNSUPPORTED_FORMAT`. The projected simple font keeps `Type`, `Subtype` (`Type1` for a `Type3` source), `BaseFont`, `FirstChar`, `LastChar` (integers 0–255), `Widths` (at most 256 finite numbers; for a `Type3` source each width times the first `FontMatrix` number times 1,000, a product over 1,000,000 in absolute value refusing as `UNSUPPORTED_FORMAT`), `ToUnicode` and the `Encoding` of BR-420; the projected Type0 font keeps `Type`, `Subtype`, `BaseFont`, `Encoding`, `ToUnicode` and one descendant with `Type`, `Subtype`, `BaseFont` (the same name), `DW` (a finite number), `W` (an array of at most 65,536 numbers in total, in the `c [w …]` and `c1 c2 w` forms, codes 0–65,535, whose ranges and arrays cover at most 65,536 CIDs in total, each `c1 c2 w` covering c2 − c1 + 1 CIDs, or none when c2 is below c1, and each `c [w …]` as many CIDs as its array has numbers, so that the widths PDF.js 6.5.438 expands stay bounded), its `FontDescriptor`, and a `CIDSystemInfo` emitted as `<< /Registry (Adobe) /Ordering (Identity) /Supplement 0 >>` after the source value is checked (a dictionary with `Registry` and `Ordering` strings of at most 64 bytes and an integer `Supplement`). The emitted `BaseFont` of every font is its canonical name of BR-415, except for a `Type1`, `MMType1` or `TrueType` font whose source `BaseFont` is exactly one of the 12 standard Latin names (`Times-Roman`, `Times-Bold`, `Times-Italic`, `Times-BoldItalic`, `Helvetica`, `Helvetica-Bold`, `Helvetica-Oblique`, `Helvetica-BoldOblique`, `Courier`, `Courier-Bold`, `Courier-Oblique`, `Courier-BoldOblique`), which keeps it so that PDF.js uses that font's standard metrics; the source `BaseFont`, a name of at most 127 bytes (optional for `Type3`), is checked and otherwise never emitted, since PDF.js 6.5.438 reads font names as hints (a system-font fallback that keeps one code point per `ToUnicode` destination for some Type0 names, the symbol and GBK encodings for simple fonts). A kept `FontDescriptor` holds `Type`, `FontName` (emitted equal to the projected `BaseFont` of the font that holds it, whatever its source value, since PDF.js 6.5.438 uses `FontName` when it differs from `BaseFont`), `FontBBox` (four finite numbers), `ItalicAngle`, `Ascent`, `Descent`, `CapHeight`, `StemV` and `MissingWidth` (finite numbers, each optional except `FontName`), and `Flags` set to the source `Flags` with the Symbolic flag (value 4) cleared and the Nonsymbolic flag (value 32) set; a simple font without a source `FontDescriptor`, and every projected `Type3` font, get none. `FontFile`, `FontFile2`, `FontFile3`, a stream `CIDToGIDMap`, `CharProcs` and `FontMatrix` are never emitted. A `ToUnicode` CMap is parsed with the bounded tokenizer: only code space ranges, `bfchar` and `bfrange` entries count; codes are 1 or 2 bytes and keyed by their numeric value; a `bfrange` has a low and high code of the same length that differ only in the last byte, low not above high, and either one destination string, incremented over the range as PDF.js 6.5.438 does, or an array whose length equals the range size; destinations are UTF-16BE strings of 2–64 bytes; when a code is mapped twice the last entry wins; `usecmap` refuses as `UNSUPPORTED_FORMAT`; every code an entry assigns counts at its assignment, a `bfchar` entry 1 and a `bfrange` entry its range size (high − low + 1), a code assigned twice counting twice; one CMap assigns at most 65,536 codes and all admitted CMaps together at most 262,144, and the entry whose assignments pass either count refuses as `LIMIT_EXCEEDED` before its range is expanded. Each `ToUnicode` stream is parsed and counted once per invocation: fonts that share one stream reuse that parse. Each admitted CMap is re-emitted canonically as one `bfchar` entry per mapped code in ascending order. Passing a bound of this rule (128 fonts, a 127-byte `BaseFont`, 256 `Widths` numbers, 65,536 `W` numbers, 65,536 CIDs covered by one `W`, 64-byte `CIDSystemInfo` strings, 64-byte destinations, the CMap code counts) refuses as `LIMIT_EXCEEDED`. Every other font refuses as `UNSUPPORTED_FORMAT`.

## Rationale

Common generators use named font resources, TrueType and Type0 subset fonts (F-034 S09–S11, S21, S25). PDF.js extracts text from encodings and `ToUnicode` without font programs (F-034 Context, finding 3), so programs, the largest parser surface, are never emitted, and Type3 fonts are projected without their glyph procedures (F-034 S32, S33); fonts take canonical names because PDF.js reads source names as hints that lose text (F-034 Measurement 3); every kept key is bounded and type-checked, and a Type0 code without a `ToUnicode` mapping refuses because only the program could give it meaning. Source: [F-034 v2](../features/F-034-pdf-extraction-profile.md).

## Examples

- **Given** a Type0 Identity-H font with `ToUnicode` and a `FontFile2` of random bytes
  **When** page 1 is read
  **Then** its text, and the canonical bytes hold no font program
- **Given** a Type0 font without `ToUnicode`
  **When** page 1 is read
  **Then** `UNSUPPORTED_FORMAT` before PDF.js
- **Given** 128 distinct fonts
  **When** page 1 is read
  **Then** its text
- **Given** 129 distinct fonts
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js
- **Given** a `ToUnicode` destination of 66 bytes
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js
- **Given** a Type0 font with a `CIDFontType2` descendant named `/ArialMT` whose `ToUnicode` maps codes to `ffi`, U+1F600 and `A`
  **When** page 1 is read
  **Then** `ffi😀A`, with `/BaseFont /K1` and `/FontName /K1` in the canonical bytes
- **Given** a Type3 font with `FontMatrix [0.001 0 0 0.001 0 0]` and a `ToUnicode` mapping its shown code to U+1F600
  **When** page 1 is read
  **Then** its text, the font projected as `/Subtype /Type1` without `CharProcs`
- **Given** a Type3 font with `FontMatrix [0.001 0.001 0 0.001 0 0]`
  **When** page 1 is read
  **Then** `UNSUPPORTED_FORMAT` before PDF.js
- **Given** a `ToUnicode` CMap of 65,536 `<00> <FF> <0041>` entries
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` at its 257th entry, before PDF.js
- **Given** a descendant `W` of 21,845 `0 65535 500` triples
  **When** page 1 is read
  **Then** `LIMIT_EXCEEDED` before PDF.js
