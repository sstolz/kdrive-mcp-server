## Rule

`ops/runner/provision.sh`, run as root inside the VM, rewrites every APT source to `https://` before the first `apt-get`, installs Docker Engine, its CLI and the Buildx and Compose plugins at exact versions named in the script from `https://download.docker.com`, configures `dockerd` with no TCP listener, builds `ops/runner/Dockerfile` as `kdrive-ci-runner:local`, creates `/home/runner/_work` owned by uid 1001, records the VM `docker` group id in `/etc/kdrive-runner/docker-gid`, and contains no `curl … | sh`, `wget … | sh` or unpinned `latest`.

## Rationale

The golden VM is built from pinned, HTTPS-only sources with a Docker daemon that listens on no TCP port (T1, T2). Source: [F-015 v1](../features/F-015-self-hosted-runner.md).

## Examples

- **Given** `ops/runner/provision.sh` as committed
  **When** the test reads it
  **Then** the HTTPS rewrite precedes the first `apt-get`, the four Docker versions are exact and `dockerd` uses `-H fd://` only
- **Given** the script with `curl https://get.docker.com | sh` appended
  **When** the test reads it
  **Then** it is rejected
