# BR-044 — Fresh collection filtering

## Rule

A collection exposes only entries individually authorized using fresh request-bound evidence; an invalid page envelope fails the page without exposing a partial page.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Expose only individually authorized fresh entries and fail conflicting pages as a whole.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** fresh permitted, outside-root and incomplete entries, **When** listing directory 11, **Then** only permitted file 13 is returned with one scope inspection.
- **Given** two entries claiming file 13 with contradictory paths, **When** listing directory 11, **Then** the entire page is denied.

Both examples map to the test or parameter rows named below.
