## Rule

Every continuation belongs to one live session, tool, effective argument set and immutable configuration/authorization context.

## Rationale

Client-held identifiers must never transfer authorization or traversal state between contexts. Source: [F-006 v1](../features/F-006-filtered-pagination.md).

## Examples

- **Given** a live list handle.
  **When** its query/tool/scope context is changed.
  **Then** INVALID_CURSOR occurs before any dependency call.
- **Given** an omitted default drive on the first request.
  **When** continuation supplies that same explicit drive.
  **Then** the normalized binding is accepted.
