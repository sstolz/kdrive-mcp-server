## Rule

The API origin, the storage-host suffix, port 443 and the BR-191 address policy are constants of `src/kdrive/`; no environment variable, CLI flag, configuration value or file changes them, and `src/kdrive/` reads no `process.env`. The only seams are the in-process exports `main(deps)` (`src/main.ts`) and the adapter factory, which accept `{lookup, connect}` and an optional read-only observer `onRequest(method, routeTemplate)` that receives no ID, query, header or body and cannot alter or cancel a request; it is called once per outgoing HTTP request (each central-helper retry and the download redirect hop included), before `connect`, and any exception it throws is caught and ignored. Throughout this spec an "injected transport" means a test `lookup` plus a test `connect` that dials a loopback TLS server serving scripted or recorded responses. Production `lookup` is `dns.lookup` with `all: true`, and production `connect` is `tls.connect` to the checked address with `servername` set to the original host and the default CA store: the adapter passes `connect` an options object whose key set is exactly `{host, port, servername}`, and production `connect` calls `tls.connect` with exactly those three members plus `rejectUnauthorized: true`, so certificate verification holds even when `NODE_TLS_REJECT_UNAUTHORIZED=0` is set, and no other TLS option (`ca`, `checkServerIdentity`, `secureContext`, `minVersion`, `maxVersion`, `ciphers`, `secureOptions`, `pfx`, `secureProtocol` or any other) is set, so Node's other defaults apply; the address policy, header handling and redirect checks run in the adapter before `connect` and cannot be replaced; `src/cli.ts`, the packaged `bin` entry, only calls `main` with the production dependencies and has no other top-level behaviour. No environment variable, CLI flag, configuration value or file enables request or response logging.

## Rationale

Any override of origin, transport or TLS options could redirect the bearer token; the seams stay in-process only. Source: [F-014 v2](../features/F-014-production-kdrive-adapter.md).

## Examples

- **Given** an environment holding `API_URL` and `HTTPS_PROXY`
  **When** `main` starts and serves `kdrive_info`
  **Then** every request targets `api.infomaniak.com`.
- **Given** an `onRequest` observer that throws
  **When** a request runs
  **Then** the result is unchanged.
- **Given** `NODE_TLS_REJECT_UNAUTHORIZED=0` and a self-signed loopback TLS server
  **When** production `connect` dials it
  **Then** the handshake fails with a certificate error.
