## Rule

Every extracted continuation uses Unicode code-point offsets in one qualified strong source version and exactly the declared selection.

## Rationale

Code-point progress must reconstruct multibyte text without mixing source versions. Source: [F-009 v1](../features/F-009-bounded-content-reading.md).

## Examples

- **Given** A😀é with a qualified ETag.
  **When** length1 chunks are resumed.
  **Then** each code point is returned exactly once.
- **Given** same-size source with a changed ETag.
  **When** offset1 uses the old tag.
  **Then** VERSION_CHANGED occurs before body open.
