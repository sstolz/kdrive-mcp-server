# BR-040 — Conservative folder sharing

## Rule

Folder sharing is denied when any deny pattern's literal prefix and the folder path are prefixes of one another, including an empty literal prefix, regardless of present descendants.

The normalized evidence, matching, effect and paging details in
[F-003 v1](../features/F-003-tree-access-policy.md) remain normative.

## Rationale

Protect denied future content through static prefix restrictions.

## Examples

These are synthetic injected cases, not provider observations.

- **Given** share mode, public links enabled and deny /r/ab/**, **When** sharing directory /r/a, **Then** the raw prefix conflict denies.
- **Given** the same directory and deny /else/**, **When** sharing it, **Then** the unrelated prefix permits.

Both examples map to the test or parameter rows named below.
