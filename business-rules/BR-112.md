## Rule

Text decoding accepts only the declared encodings with strict validation, preserves text after one leading BOM removal and never silently substitutes malformed input.

## Rationale

Silent replacement or charset guessing corrupts content and continuation offsets. Source: [F-009 v1](../features/F-009-bounded-content-reading.md).

## Examples

- **Given** Windows1252 byte0x80 explicitly selected.
  **When** decoding runs with3 decoded bytes available.
  **Then** Euro is preserved as one code point and3 UTF8 bytes.
- **Given** the same input with2 decoded bytes available.
  **When** decoding runs.
  **Then** LIMIT_EXCEEDED refuses without substitution.
