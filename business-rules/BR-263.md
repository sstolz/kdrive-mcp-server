# BR-263 — Fixed mutation tool descriptions

## Rule

Each tool description contains the fixed sentences of the F-017 Tool table for that tool and the sentence `If the result is uncertain, verify the item's state with a read tool before any new attempt.`

Since v2 (F-018): the descriptions of `kdrive_create_folder` and `kdrive_rename` also contain the sentence `name must be in Unicode NFC (composed form); other forms are refused.`

## Rationale

Clients learn the limits of each write and must not retry blindly after an unknown result. Source: [F-017 v1](../features/F-017-controlled-tree-mutations.md).

## Examples

- **Given** mode `write`
  **When** tools are listed
  **Then** the `kdrive_restore` description holds its fixed sentences and the uncertain sentence
- **Given** mode `read`
  **When** tools are listed
  **Then** no mutation tool description exists
