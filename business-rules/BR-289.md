# BR-289 — No automatic attempt after an `uncertain` upload

## Rule

An `uncertain` upload result is never followed by an automatic attempt from this server: the gate makes no further attempt (BR-251), and the tool makes no second `mutate` call.

## Rationale

A replayed upload could create a duplicate or overwrite newer content. Source: [F-018 v1](../features/F-018-upload.md).

## Examples

- **Given** a response lost after the server read the whole body
  **When** the run ends
  **Then** `uncertain`, `attempts:1`, exactly one non-GET request and no later request
- **Given** no answer until the 30,000 ms attempt abort
  **When** the run ends
  **Then** `uncertain` and no later request
