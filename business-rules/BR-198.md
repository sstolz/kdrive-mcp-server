## Rule

`inspect` of a `live` target returns the normalized complete item when the BR-199 checks pass, `{status:"missing"}` for a 404 whose error code is `object_not_found`, and `{status:"incomplete"}` for any other successful but unnormalizable response.

## Rationale

The policy facade distinguishes missing, incomplete and complete evidence; the adapter must report each exactly. Source: [F-014 v1](../features/F-014-production-kdrive-adapter.md).

## Examples

- **Given** a metadata 404 with `error.code` `object_not_found`
  **When** `inspect` runs
  **Then** it returns `{status:"missing"}`.
- **Given** a 200 envelope without `data`
  **When** `inspect` runs
  **Then** it returns `{status:"incomplete"}`.
