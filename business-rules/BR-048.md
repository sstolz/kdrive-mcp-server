# BR-048 — Validated received discovery

## Rule

Opt-in discovery exposes only validated live received-share roots from a complete dependency-acquired snapshot, after recipient-path deny checks, without treating external drives as configured drives.

The detailed frozen evidence, capability, cache and effect contracts in
[F-004 v1](../features/F-004-received-share-policy.md) are normative.

## Rationale

Discovery is an evidence boundary, not an external-drive listing.

## Examples

These are synthetic injected examples, not provider observations.

- **Given** a complete two-page list containing Project and denied Hidden roots, **When** discovering received shares, **Then** only root8:20 Project is exposed.
- **Given** a complete list with discover=false, **When** discovering received shares, **Then** no protected result is exposed and ACCESS_DENIED is returned.

Each example maps to the named parameter row/group below, in the same order.
