## Rule

A candidate redirect URI matches a reference URI when the two strings are byte-identical, or when both begin with `http://127.0.0.1`, `http://[::1]` or `http://localhost` and are byte-identical after removing from each the port suffix `:<1–5 digits>` that directly follows the host, where that suffix, when present, denotes a port from 1 to 65535 and is followed by `/`, `?` or the end of the string (RFC 8252 §7.3). Scheme, host, path and query are compared exactly; no other normalization (case, percent-encoding, trailing slash, default port, other loopback spellings) is applied.

## Rationale

Exact redirect matching prevents code theft; RFC 8252 §7.3 requires port variance for native-app loopback redirects. Source: [F-010 v1](../features/F-010-oauth-proxy.md), AC-03.

## Examples

- **Given** reference `http://127.0.0.1/callback`
  **When** `http://127.0.0.1:53121/callback` is checked
  **Then** it matches.
- **Given** reference `http://localhost/callback`
  **When** `http://localhost.evil.com/callback` is checked
  **Then** it does not match.
