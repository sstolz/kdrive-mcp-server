# BR-410 — Localisation adds no cookie, header or stored data

## Rule

Localisation adds no cookie, header or stored data: the consent page still carries exactly one `Set-Cookie` (the `__Host-kdrive-oauth` cookie of BR-130), error pages carry none, the BR-129 headers are unchanged, and the `Content-Security-Policy` is the BR-401 value with the hash of the one stylesheet, identical for both languages and every page. The page language is not written to any store, log event or the state file.

## Rationale

The owner required no new cookie and nothing stored; the CSP stays the single style hash (#31). Source: [F-031 v1](../features/F-031-oauth-proxy-page-languages.md).

## Examples

- **Given** the consent page and every error page in both languages
  **When** the headers are read
  **Then** one `__Host-kdrive-oauth` cookie on the consent page, none on error pages, and one identical CSP
- **Given** a complete French flow
  **When** the events and the state snapshot are read
  **Then** no `lang`, `fr` or `language` field appears
