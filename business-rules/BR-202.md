## Rule

`collection` serves `list` (children route), `search` (`query`, plus `directory_id` when the scope is not root `1`), `recents` and `my-shared` with `limit=50` and the same envelope rule as BR-201 v3, and returns only entries whose normalized chain or identity contains the scope directory (all entries for scope `1`).

## Rationale

Drive-wide collection routes return entries outside the configured scope; only in-scope entries may reach the policy. Source: [F-014 v5](../features/F-014-production-kdrive-adapter.md).

## Examples

- **Given** search results inside and outside folder 11
  **When** `collection` runs with scope 11
  **Then** only the entries whose chain contains 11 are returned and `directory_id=11` is sent.
- **Given** the same results
  **When** `collection` runs with scope `1`
  **Then** all entries are returned and no `directory_id` is sent.
