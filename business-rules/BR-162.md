## Rule

v2 (F-021 v1, #105; accepted on main `e208996`, 2026-11-11): v1 holds, and the process-wide windows also include `health_loopback` and `health_public`, 120 per 60 seconds each (BR-325). A `/healthz` request has no body to read; it is counted only after the shutdown, target-length, `Host`, method and framing checks of BR-322 pass, and a request refused by one of those checks or by 429 is not counted.

Process-wide windows, keyed by route, bound unauthenticated OAuth work: `/oauth/register` 30 per 3,600 seconds; `/oauth/authorize`, `/oauth/consent` and `/oauth/callback` 30 per 60 seconds each; `/oauth/token` 60 per 60 seconds. A request on these routes is counted and checked before its body is read; refusal is HTTP-layer error 429 `rate_limited` with `Retry-After`. MCP requests have no process-wide window: a request whose token verifies is never refused by one (D-7).

**v3 (F-035 v1, #46, pending acceptance; v2 stays the accepted rule until then)** — v2 holds for the two health windows (BR-325) and for MCP requests, which have no OAuth window. Each unauthenticated OAuth route has a per-peer window and a global window:

| Route       | Per peer | Global | Window length |
| ----------- | -------- | ------ | ------------- |
| `register`  | 30       | 60     | 3,600 s       |
| `authorize` | 30       | 60     | 60 s          |
| `consent`   | 30       | 60     | 60 s          |
| `callback`  | 30       | 60     | 60 s          |
| `token`     | 60       | 1,200  | 60 s          |

The peer is the BR-422 peer. Each window keeps the v1 semantics: it opens at the first counted request while none is open for its key, lasts the window length, and is full when it holds its limit. A request on these routes is checked where v1 checks it, after the shutdown, target-length, `Host`, method, framing and `Origin` checks and before its body is read: when its peer's window for the route is full it is refused with `window` `peer`; otherwise, when the route's global window is full, it is refused with `window` `global`; otherwise it is counted once in each. A refusal is the HTTP-layer error 429 `rate_limited` with `Retry-After` in whole seconds, rounded up, until the full window ends, and no handler is called. A refused request is counted in no window and adds no per-peer entry. An admitted request counts whatever the handler then answers, an invalid request included. Per-peer entries live in memory only, one table per route; before an entry is added, every entry of that table whose window has ended is removed, so a table holds fewer than twice its global limit (at most 119 entries for `register`, `authorize`, `consent` and `callback`, 2,399 for `token`).

## Rationale

Process-wide windows keep the F-010 stores below their capacity while MCP requests carry no shared window. Source: [F-012 v1](../features/F-012-authenticated-http.md), AC-11.

## Examples

- **Given** 30 registrations in 3,600 seconds
  **When** a 31st arrives
  **Then** 429 `rate_limited` and no handler call.
- **Given** 1,000 MCP requests with invalid tokens in 60 seconds
  **When** a request with a valid token arrives
  **Then** it reaches the transport.
- **Given** peer `198.51.100.1` sent 30 authorize requests within 60 seconds (v3)
  **When** it sends a 31st, and peer `203.0.113.9` sends one
  **Then** 429 `rate_limited` with `window` `peer`, and the other passes
- **Given** 60 authorize requests from 60 peers within 60 seconds (v3)
  **When** a 61st peer sends one
  **Then** 429 `rate_limited` with `window` `global`, and no entry for that peer

- **Given** legitimate clients sharing one hosted egress peer (v3)
  **When** they send 61 valid token refreshes in one minute with spare global capacity
  **Then** 60 succeed and the 61st is refused by the peer window
- **Given** a real SQLite store, ES256 signer, 20 peers and one family per peer (v3)
  **When** each peer refreshes 60 times in one fake-clock minute
  **Then** all 1,200 rotations commit and yield verifiable access tokens, persisted latest tokens survive reopening, and a fresh peer's next request hits the global ceiling without a write or signature
